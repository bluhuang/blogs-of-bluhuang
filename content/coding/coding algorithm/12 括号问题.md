# 括号问题全解：LeetCode 32 栈解法 + 通用决策框架

## 一、LeetCode 32 最长有效括号 — 栈解法精要

### 1. 题目与题型
- **题目**：给定只含 `(` 和 `)` 的字符串，找出最长有效（连续且合法）括号子串的长度。
- **题型**：括号匹配 · 最长连续有效子串

### 2. 核心思路（栈存下标）
- 栈底始终存放 **最后一个无效位置的索引**（初始值为 `-1`）。
- 遍历字符串，索引为 `i`：
  - 遇 `(`：压入下标 `i`。
  - 遇 `)`：**先弹栈**（无论栈顶是什么）。
    - 弹栈后栈空 → 当前 `)` 是新的无效断点，压入 `i`。
    - 弹栈后栈非空 → 匹配成功，有效长度 = `i - stk.top()`，更新答案。

### 3. 复杂度
- 时间：O(n)
- 空间：O(n)

### 4. C++ 实现
```cpp
int longestValidParentheses(string s) {
    stack<int> stk;
    stk.push(-1);
    int ans = 0;
    for (int i = 0; i < s.size(); ++i) {
        if (s[i] == '(') {
            stk.push(i);
        } else {
            stk.pop();
            if (stk.empty()) stk.push(i);
            else ans = max(ans, i - stk.top());
        }
    }
    return ans;
}
```

### 5. 关键细节
- **为什么存下标？** 因为需要计算长度（位置差），长度 = 当前下标 − 栈顶下标。
- **为什么栈底预存 -1？** 统一长度计算公式。当有效子串从开头即匹配时（如 `"()"`），弹栈后栈变空，有了 -1 仍可计算差值。

# 二、括号问题通用决策框架

## 核心三问
1. 用不用栈？
2. 如果用栈，存什么（字符 or 下标）？
3. 有没有更优的不用栈的解法？

## 决策表

| 问题特征 | 用栈？ | 栈存什么 | 替代解法 | 典型题目 |
|----------|--------|----------|----------|----------|
| 只判断整体有效性 | ✅ | 字符（括号本身） | 无 | LC 20 |
| 求最长连续有效子串长度 | ✅ | 下标 | DP、双向扫描 | LC 32 |
| 删除最少字符使有效 | ✅ | 下标（标记待删位置） | 无 | LC 1249 |
| 含通配符 `*` 的有效性 | 可选 | 下标（双栈法） | 贪心（高低值） | LC 678 |
| 求最少插入次数使有效 | ❌ | - | 平衡计数器 | LC 921 |
| 生成所有有效括号组合 | ❌ | - | 回溯/DFS | LC 22 |

## 决策原则速记
- 需要知道位置/长度/删除谁 → 用栈 + 存下标
- 只需知道是否合法 → 用栈 + 存字符
- 只需计数最少修改次数 → 不用栈，贪心平衡计数器
- 需要枚举所有组合 → 不用栈，回溯搜索

# 四、典型题目解法要点

### LC 20 有效的括号
- 栈存：字符
- 操作：遇左压入，遇右弹栈并检查匹配。
- 无需下标：只返回布尔值。

### LC 32 最长有效括号（栈解法）
- 栈存：下标
- 操作：初始 -1，遇 `(` 压入 `i`，遇 `)` 先弹栈，栈空则压入 `i`，否则计算 `i - stk.top()`。
- 必须存下标：长度依赖索引差。

### LC 678 有效的括号字符串
- **双栈法**：一个存 `(` 下标，一个存 `*` 下标。遇 `)` 优先匹配 `(`，其次用 `*`。最后检查剩余 `(` 能否被后面的 `*` 抵消。
- **贪心法（不用栈）**：维护 `low`、`high` 表示可能的最小/最大未匹配左括号数。遇 `*` 时 `high++`，`low--`（`low` 不低于 0）。最后 `low == 0` 即有效。

### LC 921 使括号有效的最少添加
- 不用栈：`balance` 计数。遇 `(` 加一，遇 `)` 减一；若 `balance` 变负，答案加一且重置 `balance` 为 0。最后答案加上剩余 `balance`。

### LC 1249 移除无效的括号
- 栈存：待删除括号的下标
- 操作：
  1. 遍历，遇 `(` 压栈；遇 `)` 若栈非空则弹栈，否则标记当前 `)` 待删。
  2. 遍历后栈中剩余下标对应的 `(` 也标记待删。
  3. 构造新字符串，跳过所有标记位置。

# 五、通用解法套路对比（针对连续有效括号长度）

| 方法 | 核心 | 时间复杂度 | 空间复杂度 | 能否输出子串内容 |
|------|------|------------|------------|------------------|
| 栈 | 存下标，用断点计算长度 | O(n) | O(n) | ✅ 可以 |
| 动态规划 | dp[i] 以 i 结尾的最长长度 | O(n) | O(n) | ❌ 只有长度 |
| 双向扫描 | 左右各扫一次，left/right 相等时更新 | O(n) | O(1) | ❌ 只有长度 |
