差分数组（Difference Array）详解

差分数组是一种用于高效处理区间更新操作的数据结构。它主要解决这类问题：给定一个数组，需要多次对某个区间进行加减操作，最后查询数组的最终状态。

### 什么是差分数组？

#### 基本概念

对于原始数组 `arr`，它的差分数组 `diff` 定义为：

```
diff[0] = arr[0]
diff[i] = arr[i] - arr[i-1]  (i ≥ 1)
```

#### 关键特性

**特性1**：通过差分数组可以恢复原始数组

```cpp
arr[0] = diff[0]
arr[i] = diff[0] + diff[1] + ... + diff[i]  // 对差分数组求前缀和
```

**特性2**：区间加减操作可以转换为差分数组的两个点的操作

### 图解差分数组

#### 例子1：构建差分数组

```
原始数组 arr:  [1, 3, 6, 10, 15]
索引:           0  1  2   3   4

差分数组 diff:
diff[0] = arr[0] = 1
diff[1] = arr[1] - arr[0] = 3 - 1 = 2
diff[2] = arr[2] - arr[1] = 6 - 3 = 3
diff[3] = arr[3] - arr[2] = 10 - 6 = 4
diff[4] = arr[4] - arr[3] = 15 - 10 = 5

所以 diff = [1, 2, 3, 4, 5]
```

#### 例子2：从差分数组恢复原始数组

```
差分数组 diff: [1, 2, 3, 4, 5]

恢复 arr:
arr[0] = diff[0] = 1
arr[1] = arr[0] + diff[1] = 1 + 2 = 3
arr[2] = arr[1] + diff[2] = 3 + 3 = 6
arr[3] = arr[2] + diff[3] = 6 + 4 = 10
arr[4] = arr[3] + diff[4] = 10 + 5 = 15
```

### 差分数组的威力：区间更新

#### 传统方法 vs 差分数组

**问题**：将数组 `arr` 中区间 `[l, r]` 的所有元素都加上 `val`

**传统方法**：O(n) 复杂度

```cpp
for (int i = l; i <= r; i++) {
    arr[i] += val;
}
```

**差分数组方法**：O(1) 复杂度

```cpp
diff[l] += val;
if (r + 1 < n) {
    diff[r + 1] -= val;
}
```

#### 为什么这样有效？

**核心原理**：

- 对 `diff[l] += val` 意味着：从位置 `l` 开始，所有元素都加上了 `val`
- 对 `diff[r+1] -= val` 意味着：从位置 `r+1` 开始，所有元素都减去了 `val`

这样，只有区间 `[l, r]` 的元素最终效果是加了 `val`。

#### 图解示例

```
原始数组 arr: [1, 3, 6, 10, 15]
差分数组 diff: [1, 2, 3, 4, 5]

现在要对区间 [1, 3] 的所有元素加 5

传统方法：
arr[1] += 5 → 3+5=8
arr[2] += 5 → 6+5=11
arr[3] += 5 → 10+5=15
结果：arr = [1, 8, 11, 15, 15]

差分数组方法：
diff[1] += 5 → diff[1] = 2+5=7
diff[4] -= 5 → diff[4] = 5-5=0
新的 diff = [1, 7, 3, 4, 0]

恢复 arr:
arr[0] = 1
arr[1] = 1+7=8
arr[2] = 8+3=11
arr[3] = 11+4=15
arr[4] = 15+0=15
结果：arr = [1, 8, 11, 15, 15] ✓
```

### 差分数组的实现

#### 1. 构建差分数组

```cpp
vector<int> buildDiffArray(const vector<int>& arr) {
    int n = arr.size();
    vector<int> diff(n);
    
    diff[0] = arr[0];
    for (int i = 1; i < n; i++) {
        diff[i] = arr[i] - arr[i-1];
    }
    
    return diff;
}
```

#### 2. 区间更新

```cpp
void rangeUpdate(vector<int>& diff, int l, int r, int val) {
    diff[l] += val;
    if (r + 1 < diff.size()) {
        diff[r + 1] -= val;
    }
}
```

#### 3. 恢复原始数组

```cpp
vector<int> restoreArray(const vector<int>& diff) {
    int n = diff.size();
    vector<int> arr(n);
    
    arr[0] = diff[0];
    for (int i = 1; i < n; i++) {
        arr[i] = arr[i-1] + diff[i];
    }
    
    return arr;
}
```

### 应用实例

**LeetCode 1109. 航班预订统计**

**问题**：

```
有 n 个航班，分别从 1 到 n 编号。
预订记录 bookings[i] = [first_i, last_i, seats_i]
表示在从 first_i 到 last_i 的每个航班上预订了 seats_i 个座位。

返回长度为 n 的数组 answer，其中 answer[i] 是航班 i 上预订的座位总数。
```

**示例**：

```
输入：bookings = [[1,2,10],[2,3,20],[2,5,25]], n = 5
输出：[10,55,45,25,25]
```

**差分数组解法**：

```cpp
vector<int> corpFlightBookings(vector<vector<int>>& bookings, int n) {
    // 初始化差分数组（所有航班初始为0）
    vector<int> diff(n, 0);
    
    // 应用每个预订记录
    for (auto& booking : bookings) {
        int first = booking[0] - 1;  // 转为0-based索引
        int last = booking[1] - 1;
        int seats = booking[2];
        
        diff[first] += seats;
        if (last + 1 < n) {
            diff[last + 1] -= seats;
        }
    }
    
    // 通过差分数组恢复最终结果
    vector<int> answer(n);
    answer[0] = diff[0];
    for (int i = 1; i < n; i++) {
        answer[i] = answer[i-1] + diff[i];
    }
    
    return answer;
}
```

**图解示例**

```
n = 5, 初始所有航班座位数都为0
diff = [0, 0, 0, 0, 0]

预订1: [1,2,10] (0-based: [0,1,10])
diff[0] += 10 → diff = [10, 0, 0, 0, 0]
diff[2] -= 10 → diff = [10, 0, -10, 0, 0]

预订2: [2,3,20] (0-based: [1,2,20])
diff[1] += 20 → diff = [10, 20, -10, 0, 0]
diff[3] -= 20 → diff = [10, 20, -10, -20, 0]

预订3: [2,5,25] (0-based: [1,4,25])
diff[1] += 25 → diff = [10, 45, -10, -20, 0]
diff[5] 不存在，不操作

恢复结果：
answer[0] = 10
answer[1] = 10+45=55
answer[2] = 55+(-10)=45
answer[3] = 45+(-20)=25
answer[4] = 25+0=25
结果: [10,55,45,25,25] ✓
```

### 差分数组的优点和局限

**优点**：

1. 高效的区间更新：O(1) 时间复杂度完成区间加减
2. 空间效率：只需要额外的 O(n) 空间
3. 简单易实现：逻辑清晰，代码简洁

**局限**：

1. 仅支持加减操作：不支持区间乘除等其他操作
2. 不适合频繁查询：每次查询需要 O(n) 时间恢复数组
3. 需要离线操作：通常先进行所有更新，最后一次性查询

### 扩展：二维差分数组

差分数组也可以扩展到二维，用于矩阵的区间更新：

```cpp
// 二维差分数组更新：将子矩阵 (x1,y1) 到 (x2,y2) 的所有元素加 val
void update2D(vector<vector<int>>& diff, int x1, int y1, int x2, int y2, int val) {
    diff[x1][y1] += val;
    diff[x1][y2+1] -= val;
    diff[x2+1][y1] -= val;
    diff[x2+1][y2+1] += val;
}
```

### 总结

差分数组的核心思想是：

1. 用相邻元素的差值表示数组
2. 区间更新转换为两个端点的操作
3. 通过前缀和恢复最终结果

它特别适合解决“多次区间加减操作，最后查询结果”这类问题。理解差分数组可以帮助你高效解决许多区间更新相关的算法问题。
