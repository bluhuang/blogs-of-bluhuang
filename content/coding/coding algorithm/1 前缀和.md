## 什么是前缀和？

**前缀和**是一种数据预处理技术，用于快速计算数组中任意区间的和。它的核心思想是：
> 预先计算出从数组开头到每个位置的元素和，这样任意区间[i, j]的和就可以通过两个前缀和的差值快速得到。

```
prefix[0] = 0                     (空数组的和)
prefix[1] = a₀                    = prefix[0] + nums[0]
prefix[2] = a₀ + a₁               = prefix[1] + nums[1]
prefix[3] = a₀ + a₁ + a₂          = prefix[2] + nums[2]
...
prefix[i] = a₀ + a₁ + ... + aᵢ₋₁  = prefix[i-1] + nums[i-1]
```

### 关键公式

对于任意区间 `[i, j]`（包含两端）：
```
sum(i, j) = nums[i] + nums[i+1] + ... + nums[j]
          = prefix[j+1] - prefix[i]
```

## 为什么前缀和有用？

**传统方法**：每次计算区间和需要遍历该区间，时间复杂度O(n)  
**前缀和方法**：只需一次减法操作，时间复杂度O(1)（前提是已经计算出前缀和）

## 计算区间和

```
求 nums[1] + nums[2] + nums[3] = 2 + 3 + 4 = 9

传统方法: 遍历索引1,2,3 → 2+3+4=9

前缀和方法:
sum(1, 3) = prefix[4] - prefix[1] 
          = 10 - 1 = 9
```

### 相关题目
#### 560. 和为K的子数组

### 问题转换

我们要找的是连续子数组和为k，即：

```
nums[i] + nums[i+1] + ... + nums[j] = k
```

使用前缀和表示：

```
prefix[j+1] - prefix[i] = k
```

对于当前的前缀和 `prefix[j+1]`，我们只需要知道在它之前有多少个 `prefix[i]` 等于 `prefix[j+1] - k`！

换句话说：
- 我们一边计算前缀和
- 一边用哈希表记录每个前缀和出现的次数
- 对于当前前缀和 `sum`，查找 `sum - k` 出现过多少次
