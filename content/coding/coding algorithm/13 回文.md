# 回文（Palindrome）串题型完整笔记

## 一、题型识别与核心特征

所有回文串问题都围绕一个核心定义：
> **回文串**：正着读和倒着读一样的字符串。

问题类型通常分为三类：
1. **验证/计数型**：判断是否是回文、统计回文子串数量。
2. **构造/分割型**：分割出所有回文子串（回溯）、最少分割次数（DP）。
3. **最长/极值型**：找最长的回文子串。

所有问题的根基都是**如何高效判断一个子串是回文**。一旦熟练掌握了子串回文的判断，所有问题无非是在此基础上**遍历、计数、分割或求极值**。

| 题型       | 代表题目                                                                                                   | 核心解法               |
| :------- | :----------------------------------------------------------------------------------------------------- | :----------------- |
| 最长回文子串   | [5. Longest Palindromic Substring](https://leetcode.com/problems/longest-palindromic-substring/)       | 中心扩展法 / 二维DP       |
| 回文子串计数   | [647. Palindromic Substrings](https://leetcode.com/problems/palindromic-substrings/)                   | 中心扩展法 / 二维DP       |
| 验证回文串    | [125. Valid Palindrome](https://leetcode.com/problems/valid-palindrome/)                               | 双指针（跳过非字母数字）       |
| 验证回文串 II | [680. Valid Palindrome II](https://leetcode.com/problems/valid-palindrome-ii/)                         | 双指针 + 递归/贪心（最多删一个） |
| 分割回文串    | [131. Palindrome Partitioning](https://leetcode.com/problems/palindrome-partitioning/)                 | 回溯 + 二维DP预判断       |
| 分割回文串 II | [132. Palindrome Partitioning II](https://leetcode.com/problems/palindrome-partitioning-ii/)           | 二维DP + 一维DP优化      |
| 最长回文子序列  | [516. Longest Palindromic Subsequence](https://leetcode.com/problems/longest-palindromic-subsequence/) | 二维区间DP（区别于子串）      |
| 回文对      | [336. Palindrome Pairs](https://leetcode.com/problems/palindrome-pairs/)                               | 哈希表 + 字符串反转匹配      |

## 二、常见误区：为什么“从两边向中间验证”不能用来找最长子串？

可能下意识会想：
> “只要枚举每一个子串起点和终点，然后用双指针从两边向中间验证它是不是回文，最后记录最长的就行了。”

这个思路逻辑完全正确，但时间复杂度过高。

- 枚举所有子串需要 O(n²) 个起点-终点对。
- 每次验证又是 O(n) 的时间。
- 总时间复杂度高达 **O(n³)**，在 n=1000 时基本会超时。

**结论**：
> **从两边向中间的双指针是验证已知子串的完美方法（用于 125、680 等题），但不适合用来“搜索”最长回文子串。**
> 搜索场景下，使用**中心扩展法**（O(n²) 时间，O(1) 空间）或**动态规划**（O(n²) 时间，O(n²) 空间）。

## 三、基础：判断子串是否回文的两种方法

### 1. 双指针中心扩展法（推荐，O(1) 空间）

从中心向两边扩展，一次遍历即可同时处理奇数和偶数长度。

```cpp
// 在 s 上以 left, right 为中心向两边扩展，返回能扩展的最大回文长度
int expandAroundCenter(const string &s, int left, int right) {
    while (left >= 0 && right < s.size() && s[left] == s[right]) {
        left--;
        right++;
    }
    return right - left - 1; // 实际回文长度
}
```

### 2. 二维动态规划（适合一次性判断多个子串）

```cpp
int n = s.size();
vector<vector<bool>> dp(n, vector<bool>(n, false));
int maxLen = 1, start = 0;

for (int j = 0; j < n; ++j) {
    for (int i = 0; i <= j; ++i) {
        if (s[i] == s[j] && (j - i <= 2 || dp[i+1][j-1])) {
            dp[i][j] = true;
            // 更新 maxLen 和 start
        }
    }
}
```

## 四、必考题深度解析

### 题目 1：最长回文子串（LeetCode 5）

**题目要求**：给定一个字符串 `s`，找到 `s` 中最长的回文子串。如果存在多个，返回任意一个。

**思路**：遍历每个字符，以它为中心（奇数长度）和以它及下一个字符为中心（偶数长度）向两边扩展，记录能扩展到的最长回文子串的起点和长度。

**代码**：
```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        if (s.empty()) return "";
        int start = 0, maxLen = 1;
        for (int i = 0; i < s.size(); ++i) {
            int len1 = expand(s, i, i);     // 奇数长度中心
            int len2 = expand(s, i, i + 1); // 偶数长度中心
            int len = max(len1, len2);
            if (len > maxLen) {
                maxLen = len;
                start = i - (len - 1) / 2;
            }
        }
        return s.substr(start, maxLen);
    }
    
    int expand(const string &s, int left, int right) {
        while (left >= 0 && right < s.size() && s[left] == s[right]) {
            left--;
            right++;
        }
        return right - left - 1;
    }
};
```

### 题目 2：回文子串计数（LeetCode 647）

**题目要求**：给定一个字符串 `s`，统计并返回这个字符串中回文子串的数目。

**思路**：与上一题完全相同，只是将“记录最长长度”改为“每扩展一步，计数器加一”。

**代码**：
```cpp
class Solution {
public:
    int countSubstrings(string s) {
        int count = 0;
        for (int i = 0; i < s.size(); ++i) {
            count += expandCount(s, i, i);
            count += expandCount(s, i, i + 1);
        }
        return count;
    }
    
    int expandCount(const string &s, int left, int right) {
        int cnt = 0;
        while (left >= 0 && right < s.size() && s[left] == s[right]) {
            cnt++;
            left--;
            right++;
        }
        return cnt;
    }
};
```

### 题目 3：验证回文串（LeetCode 125）

**题目要求**：给定一个字符串 `s`，验证它是否是回文串，只考虑字母和数字字符，忽略大小写。

**思路**：双指针从两端向中间扫描，跳过非字母数字字符，比较时统一转成小写。

**代码**：
```cpp
class Solution {
public:
    bool isPalindrome(string s) {
        int left = 0, right = s.size() - 1;
        while (left < right) {
            while (left < right && !isalnum(s[left])) left++;
            while (left < right && !isalnum(s[right])) right--;
            if (tolower(s[left]) != tolower(s[right])) return false;
            left++;
            right--;
        }
        return true;
    }
};
```

### 题目 4：验证回文串 II（LeetCode 680）

**题目要求**：给定一个非空字符串 `s`，最多删除一个字符，判断是否能成为回文串。

**思路**：先用双指针从两端向中间比较，遇到不相等时，分别尝试跳过左边或跳过右边，判断剩下的子串是否为回文。

**代码**：
```cpp
class Solution {
public:
    bool validPalindrome(string s) {
        int left = 0, right = s.size() - 1;
        while (left < right) {
            if (s[left] != s[right]) {
                return isPalindrome(s, left + 1, right) || 
                       isPalindrome(s, left, right - 1);
            }
            left++;
            right--;
        }
        return true;
    }
    
    bool isPalindrome(const string &s, int left, int right) {
        while (left < right) {
            if (s[left] != s[right]) return false;
            left++;
            right--;
        }
        return true;
    }
};
```

### 题目 5：分割回文串（LeetCode 131）

#### 题目要求
给定一个字符串 `s`，将 `s` 分割成一些子串，使每个子串都是回文串。返回**所有可能的分割方案**。

#### 详细思路
这个问题需要输出所有合法的切分方式，自然想到**回溯（DFS）**。

想象站在字符串的某个位置 `start`，需要决定从哪里切一刀。切下去的前提是**当前这段子串必须是回文**。如果 `s[start..end]` 是回文，就把它放入当前路径，然后递归处理剩余部分 `end+1`。当 `start` 走到字符串末尾时，就把整条路径加入结果。

问题是在回溯过程中，需要反复检查 `s[start..end]` 是不是回文。如果每次都用双指针验证，重复计算太多。因此**先用二维 DP 预处理**出任意区间 `[i,j]` 是否为回文。之后回溯时判断就是 O(1) 的了。

**DP 预处理**：
- `dp[i][j]` 表示 `s[i..j]` 是否为回文。
- 转移：`s[i] == s[j]` 且（区间长度 ≤2 或 `dp[i+1][j-1]` 为真）。
- 填表顺序：按子串长度从小到大或右边界 `j` 递增。

#### 代码
```cpp
class Solution {
public:
    vector<vector<string>> partition(string s) {
        int n = s.size();
        // 1. DP 预处理所有子串的回文性
        vector<vector<bool>> dp(n, vector<bool>(n, false));
        for (int j = 0; j < n; ++j)
            for (int i = 0; i <= j; ++i)
                if (s[i] == s[j] && (j - i <= 2 || dp[i+1][j-1]))
                    dp[i][j] = true;
        
        // 2. 回溯收集所有分割方案
        vector<vector<string>> res;
        vector<string> path;
        
        function<void(int)> dfs = [&](int start) {
            if (start == n) {
                res.push_back(path);
                return;
            }
            for (int end = start; end < n; ++end) {
                if (dp[start][end]) {
                    path.push_back(s.substr(start, end - start + 1));
                    dfs(end + 1);
                    path.pop_back();
                }
            }
        };
        
        dfs(0);
        return res;
    }
};
```

### 题目 6：分割回文串 II（LeetCode 132，最少分割次数）

#### 题目要求
给定一个字符串 `s`，将 `s` 分割成一些子串，使每个子串都是回文串。返回符合要求的**最少分割次数**。

#### 详细思路
上一题是求“所有方案”，这题是求“最少切几刀”。这是一个典型的**最优子结构**问题，适合用动态规划。

定义 `dp[i]` 表示：将前缀 `s[0..i-1]` 分割成全回文子串所需的**最少分割次数**。
- 初始条件：空字符串不需要分割，但为了方便计算，设 `dp[0] = -1`（这样当整个字符串本身是回文时，`dp[n] = -1 + 1 = 0`，符合逻辑）。

状态转移：对于每个 `i`（1 到 n），枚举上一个分割点 `j`（0 到 i-1）。如果子串 `s[j..i-1]` 是回文，那么可以通过在 `dp[j]` 的基础上再切一刀得到 `dp[i]`：
```
dp[i] = min(dp[i], dp[j] + 1)
```

同样需要快速判断任意子串是否为回文，因此仍然**复用上一题的二维 DP 预处理**。

**举例**：`s = "aab"`
- 预处理回文：`"a"`, `"aa"`, `"aab"` 不是，`"a"`, `"ab"` 不是，`"b"`。
- 求 `dp`：
  - `dp[0] = -1`
  - i=1 (`"a"`): j=0 时 `"a"` 回文 → `dp[1] = dp[0]+1 = 0`
  - i=2 (`"aa"`): j=0 时 `"aa"` 回文 → `dp[2]=0`；j=1 时 `"a"` 回文 → `min(0, dp[1]+1=1)` → 0
  - i=3 (`"aab"`): j=2 时 `"b"` 回文 → `dp[3] = dp[2]+1 = 1`；j=1 时 `"ab"` 不是；j=0 时 `"aab"` 不是 → 最终 1，即切一刀（`"aa" | "b"`）。

#### 代码
```cpp
class Solution {
public:
    int minCut(string s) {
        int n = s.size();
        // 1. 二维 DP 预处理任意区间是否回文
        vector<vector<bool>> pal(n, vector<bool>(n, false));
        for (int j = 0; j < n; ++j)
            for (int i = 0; i <= j; ++i)
                if (s[i] == s[j] && (j - i <= 2 || pal[i+1][j-1]))
                    pal[i][j] = true;
        
        // 2. 一维 DP 求最少分割次数
        vector<int> dp(n + 1, INT_MAX);
        dp[0] = -1; // 空字符串分割次数为 -1
        for (int i = 1; i <= n; ++i) {
            for (int j = 0; j < i; ++j) {
                if (pal[j][i-1]) {
                    dp[i] = min(dp[i], dp[j] + 1);
                }
            }
        }
        return dp[n];
    }
};
```

### 题目 7：最长回文子序列（LeetCode 516）

#### 题目要求
给定一个字符串 `s`，找出其中最长的回文子序列，并返回其长度。**子序列**定义为不改变剩余字符顺序的情况下删除某些字符得到的序列。

#### 详细思路
注意关键点是**子序列**，不是子串。子序列不要求连续，因此不能用滑动窗口或中心扩展，必须用**区间动态规划**。

定义 `dp[i][j]` 表示：子串 `s[i..j]` 中，最长回文子序列的长度。
- 基础情况：`i == j` 时，单个字符长度为 1。
- 状态转移：
  - 如果 `s[i] == s[j]`，那么这两个字符可以同时作为新回文子序列的两端，这样长度 = `dp[i+1][j-1] + 2`。
  - 如果 `s[i] != s[j]`，那么说明这两个字符不能同时出现在最终的回文子序列中，只能取其一：要么舍弃左边取 `dp[i+1][j]`，要么舍弃右边取 `dp[i][j-1]`，取二者最大值。

**填表顺序**：由于大区间依赖小区间，按长度 `len` 从小到大遍历，或以 `i` 从大到小、`j` 从小到大遍历。

**举例**：`s = "bbbab"`
- 长度1：`dp[0][0]=1`, `dp[1][1]=1`, ...
- 长度2：`dp[0][1]` (`"bb"`)：相等 → 2；`dp[3][4]` (`"ab"`)：不等 → max(dp[3][3], dp[4][4]) = 1。
- 长度3：`dp[0][2]` (`"bbb"`)：相等 → dp[1][1] + 2 = 3；...
- 最终 `dp[0][4]` = 4（`"bbbb"`）。

#### 代码
```cpp
class Solution {
public:
    int longestPalindromeSubseq(string s) {
        int n = s.size();
        vector<vector<int>> dp(n, vector<int>(n, 0));
        // 单个字符的回文子序列长度为 1
        for (int i = 0; i < n; ++i) dp[i][i] = 1;
        
        for (int len = 2; len <= n; ++len) {
            for (int i = 0; i + len - 1 < n; ++i) {
                int j = i + len - 1;
                if (s[i] == s[j]) {
                    dp[i][j] = dp[i+1][j-1] + 2;
                } else {
                    dp[i][j] = max(dp[i+1][j], dp[i][j-1]);
                }
            }
        }
        return dp[0][n-1];
    }
};
```

### 题目 8：回文对（LeetCode 336）

#### 题目要求
给定一组**互不相同**的单词，找出所有不同的索引对 `(i, j)`，使得两个单词拼接后（`words[i] + words[j]`）是回文串。

#### 详细思路
暴力枚举所有 O(n²) 对并检查会超时。需要更高效的方法。

核心观察：假设存在两个单词 `A` 和 `B` 使得 `A + B` 是回文。`A` 的长度为 `lenA`，`B` 的长度为 `lenB`。
设 `len = lenA + lenB`。由于是回文，必然存在一个“对称轴”。根据对称轴的位置，可以把 `A` 切分成两段：`A = A1 + A2`。
- 如果对称轴在 `A` 内部较后的位置，即 `A2` 长度 > `B` 长度，那么 `A1` 必须是回文，且 `A2` 的反转必须等于 `B`。
- 如果对称轴在 `B` 内部或交界处，即 `B1` 长度 ≥ `A` 长度，那么 `B2` 必须是回文，且 `B1` 的反转必须等于 `A`。

统一处理方式：对于每个单词，枚举它的**切割点**，将单词分成 `left` 和 `right` 两部分。分两种情况判断：
1. **`left` 是回文**：那么 `right` 的反转如果存在于字典中，就可以拼在左边。即 `reverse(right) + 当前单词` 构成回文。注意索引顺序：此时 `reverse(right)` 是 `words[j]`，当前单词是 `words[i]`，所以答案是 `[dict[reverse(right)], i]`。
2. **`right` 是回文**：那么 `left` 的反转如果存在于字典中，就可以拼在右边。即 `当前单词 + reverse(left)` 构成回文。答案是 `[i, dict[reverse(left)]]`。

需要注意的是：
- 要避免自己和自己拼的情况（题目确保所有单词不同，但切割时可能整词匹配到自己，因此需要检查索引不同）。
- 当 `right` 为空时（即切割点在最右），它与情况 1 中 `left` 为空的情况对称（此时对应整个单词本身就是回文且存在空串），若题目中没有空串，可省略或通过条件控制重复。

**举例**：`words = ["abcd","dcba","lls","s","sssll"]`
- 单词 `"lls"`，切割成 `left="ll"`（回文），`right="s"`。`reverse(right)="s"` 在字典中（索引3）。于是拼接 `"s" + "lls" = "slls"` 是回文，添加 `[3, 2]`。

#### 代码
```cpp
class Solution {
public:
    vector<vector<int>> palindromePairs(vector<string>& words) {
        unordered_map<string, int> dict;
        for (int i = 0; i < words.size(); ++i) {
            string rev = words[i];
            reverse(rev.begin(), rev.end());
            dict[rev] = i;   // 存储反转后的单词到原索引的映射
        }
        
        vector<vector<int>> res;
        for (int i = 0; i < words.size(); ++i) {
            string word = words[i];
            int n = word.size();
            // 枚举切割点，将 word 分成 [0, j-1] 和 [j, n-1]
            for (int j = 0; j <= n; ++j) {
                string left = word.substr(0, j);
                string right = word.substr(j);
                
                // 情况 1：左边是回文
                if (isPalindrome(left)) {
                    string rightRev = right;
                    reverse(rightRev.begin(), rightRev.end());
                    if (dict.count(rightRev) && dict[rightRev] != i) {
                        res.push_back({dict[rightRev], i});
                    }
                }
                // 情况 2：右边是回文（且 right 非空，避免与情况 1 完全对称重复）
                if (!right.empty() && isPalindrome(right)) {
                    string leftRev = left;
                    reverse(leftRev.begin(), leftRev.end());
                    if (dict.count(leftRev) && dict[leftRev] != i) {
                        res.push_back({i, dict[leftRev]});
                    }
                }
            }
        }
        return res;
    }
    
    bool isPalindrome(const string &s) {
        int left = 0, right = s.size() - 1;
        while (left < right) {
            if (s[left++] != s[right--]) return false;
        }
        return true;
    }
};
```

## 五、回文串问题通用记忆框架

| 方法 | 适用场景 | 代码难度 |
| :--- | :--- | :--- |
| **双指针中心扩展** | 最长子串、计数 | ⭐ 最简单，必会 |
| **二维 DP** | 需要频繁判断任意区间是否为回文（如分割问题） | ⭐⭐ |
| **双指针（两端向中间）** | 带干扰字符的验证 | ⭐ 简单 |

**关键总结**：
1. 验证单个回文用“两端双指针”；搜索或构造回文用“中心扩展”或“二维 DP”。
2. 要求输出所有方案 → 回溯 + DP 预处理。
3. 要求最优解（如最少次数） → 一维/二维 DP，依赖预处理的回文表。
4. 子序列问题天然不能用中心扩展，必须用区间 DP。
