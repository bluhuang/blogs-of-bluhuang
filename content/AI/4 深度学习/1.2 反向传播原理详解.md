# 反向传播详解

这个循环是深度学习的“心脏”，每训练一个batch（一小批数据）就跳一次。

```text
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌──────────┐    ┌────────┐
│  数据   │───→│  模型   │───→│  损失    │───→│ 反向传播 │───→│ 优化器 │
│ (Data)  │    │(Model)  │    │ (Loss)  │    │   (BP)   │    │(Optim) │
└─────────┘    └─────────┘    └─────────┘    └──────────┘    └───┬────┘
    ^                                                            │
    └───-───-───-───-───-───-───-───-───-───-───-───-────────────┘
                        更新模型参数 ──→ 回到“数据”
```

# 数学基础
## 1. 先理解“导数”——变化的速率

导数在数学上就是 “变化率” ，即“输出变化量”除以“输入变化量”。

生活例子：你开车看速度表，时速 60 公里。

速度就是“距离”对“时间”的导数。

它告诉你：时间每增加 1 小时，距离大约增加 60 公里。

导数关注的核心问题：如果我把输入 $x$ 稍微调大一丁点，输出 $y$ 会变多少？

## 2. 什么是“偏导数”？（锁定其他变量，只盯一个）

当函数有多个输入时（比如 $y = w_1 x_1 + w_2 x_2$），你想看某一个输入单独对输出的影响，就得先把其他输入固定住，只看这一个。这个“单独的影响系数”就叫偏导数。

生活例子：一份炒饭好不好吃（$y$），取决于“盐量”（$x_1$）和“火候”（$x_2$）。

你想知道“盐量”单独的影响力：

把火候固定在中火（锁定 $x_2$）。

只把盐从 5克 增加到 6克，发现好吃程度从 7分 涨到了 8分。

盐的偏导数 ≈ $(8-7)/(6-5) = 1$。意思是：在火候不变的条件下，每多放 1 克盐，好吃度提高 1 分。

在你的神经网络里：

$y$ 就是 Loss（损失值）。

$x_1$ 可能是第 1 层的某个权重 $w_1$，$x_2$ 是另一个权重 $w_2$。

偏导数 $\partial L / \partial w_1$ 告诉你：保持其他所有权重不动，只把 $w_1$ 增加一点点，Loss 会变大还是变小？

这就是反向传播要算的东西！每个参数算一个偏导数。

## 3. 什么是“链式法则”？（多层传递的乘法规则）

现实中的函数往往是嵌套的：$A$ 影响 $B$，$B$ 影响 $C$。你想知道“最开始的 $A$ 变化 1 单位，最后的 $C$ 变化多少？”答案是：把每一段的变化率乘起来。

生活例子（很经典）：

- $A$（自变量）：你每天多加班 1 小时。
- $B$（中间变量）：加班导致项目产出提升，每多 1 小时产出提升 10 行代码。
- $C$（最终变量）：产出提升导致年终奖增加，每多 10 行代码，年终奖多 100 块。

问：多加班 1 小时，年终奖多了多少？

计算：$100$（元/10行） $\times$ $10$（行/小时） $= 1000$（元/小时）。

这就是链式法则：把变化率一路乘过去。

## 4. 把“偏导数”和“链式法则”放到反向传播里（看具体数字）

假设一个极简网络（忽略激活函数）：

- 输入 $x = 2$
- 第 1 层权重 $w_1 = 3$，计算 $h = w_1 \times x = 6$
- 第 2 层权重 $w_2 = 4$，计算 $\hat{y} = w_2 \times h = 24$
- 真实值 $y_{true} = 30$
- Loss = $(\hat{y} - y_{true})^2 = (24 - 30)^2 = 36$

现在，我们想知道“调整 $w_1$ 对 Loss 的影响”（即偏导数 $\partial L / \partial w_1$）。

步骤拆解（链式法则的三段乘法）：

**第一段：输出层误差对 Loss 的导数。**

Loss = $(\hat{y} - 30)^2$。

如果 $\hat{y}$ 增加 1（变成 25），Loss = $(25 - 30)^2 = 25$，从 36 降到了 25，变化了 -11。

导数约等于 $-11 / 1 = -11$。（数学精确值是 -12，懂这个意思就行）

**第二段：隐藏层输出 $h$ 对输出 $\hat{y}$ 的导数。**

$\hat{y} = w_2 \times h$，这里 $w_2 = 4$。

如果 $h$ 增加 1，$\hat{y}$ 增加 4。

导数是 4。

**第三段：权重 $w_1$ 对隐藏层 $h$ 的导数。**

$h = w_1 \times x$，这里 $x = 2$。

如果 $w_1$ 增加 1，$h$ 增加 2。

导数是 2。

**最后，应用链式法则（把这三段乘起来）：**

$$
\frac{\partial L}{\partial w_1} = \text{(第一段)} \times \text{(第二段)} \times \text{(第三段)} = (-12) \times 4 \times 2 = -96
$$

**结果解读：**

算出来的偏导数是 -96（负数）。

意味着：如果我把 $w_1$ 稍微调大一点点，Loss 会急剧下降（因为负号）。

优化器看到这个数，就会欢快地增加 $w_1$，因为这是让 Loss 快速降低的正确方向。

## 一句话总结偏导数与链式法则

| 概念 | 大白话定义 | 在反向传播中的作用 |
|------|-----------|-------------------|
| 偏导数 | 固定其他所有东西，只看这一个参数变化时，Loss 会变多少。 | 算出每个权重的“专属调整方向”。 |
| 链式法则 | 当变化需要经过多层传递时，把每一层的“变化率”乘起来，就算出源头对最终结果的影响。 | 把输出层的误差“搬运”回前几层的权重上，让浅层也能知道自己该怎么改。 |

下次你看到 `loss.backward()` 这一行代码，就可以在脑子里想象：PyTorch 正在从后往前，把每一层的偏导数（变化率）像乘法口诀一样链式乘起来，最后把结果填到每个权重的 `.grad` 属性里。这就是神经网络学习的全部数学秘密。

# 前向传播与反向传播的推导过程

## 一个极简网络（两层，无激活函数）

```text
     输入        第1层          第2层         输出            Loss
     (已知)     (权重w1)      (权重w2)      (预测值)
     
     x = 2  ──→  h = w1 * x  ──→  ŷ = w2 * h  ──→  L = (ŷ - y_true)²
                   w1 = 3          w2 = 4           y_true = 30
                   
    前向传播计算结果：
    h = 3 * 2 = 6
    ŷ = 4 * 6 = 24
    L = (24 - 30)² = 36
```

---

## 第一步：前向传播（数据从左往右流）

```text
   ┌──────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
   │      │    │              │    │              │    │              │
   │ x=2  │───→│  h = w1 * x  │───→│  ŷ = w2 * h  │───→│  L = (ŷ-30)² │
   │      │    │    w1=3      │    │    w2=4      │    │   = 36       │
   └──────┘    └──────────────┘    └──────────────┘    └──────────────┘
                    ↑                    ↑
               可调参数              可调参数
```

**前向传播就是：输入 \( x=2 \) 从左到右，经过两个参数节点，最终算出 Loss = 36。**

---

## 第二步：反向传播的目的（从右往左推）

反向传播要回答的问题是：

> **如果我把 w1 稍微调大一点点，Loss 会变多少？如果调 w2 呢？**

我们分两个方向推：先推 **w2**（靠近输出，简单），再推 **w1**（靠近输入，需要链式法则）。

---

## 第三步：算 w2 的偏导数（直接，不需要链式法则）

把 w1 固定住（锁死为 3），只动 w2。

```text
           固定不动 ↓
   ┌──────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
   │      │    │              │    │              │    │              │
   │ x=2  │───→│  h = 3*2=6   │───→│  ŷ = w2 * 6  │───→│  L = (ŷ-30)² │
   │      │    │              │    │    ↑         │    │              │
   └──────┘    └──────────────┘    │   w2 可调    │    └──────────────┘
                                    └──────────────┘
                                                      
    如果 w2 从 4 变成 5（增加 1）：
    ŷ = 5 * 6 = 30（从 24 变成 30）
    L = (30 - 30)² = 0（从 36 变成 0）
    
    w2 对 Loss 的影响 = (0 - 36) / (5 - 4) = -36 / 1 = -36
    偏导数 ∂L/∂w2 = -36
```

**解读**：w2 增加 1，Loss 下降 36。所以优化器会**增加 w2** 来降低 Loss。

---

## 第四步：算 w1 的偏导数（需要链式法则，因为中间隔了一层）

w1 的变化要经过 **w1 → h → ŷ → L** 这条链路才能影响 Loss。我们把每一段的“变化率”算出来，然后乘起来。

```text
   ┌─────────────────────────────────────────────────────────────────────────────┐
   │                         链式法则：把三段变化率相乘                           │
   │                                                                           │
   │    w1 变化  ──→  h 变化  ──→  ŷ 变化  ──→  L 变化                         │
   │       ↑              ↑             ↑             ↑                        │
   │    ∂h/∂w1        ∂ŷ/∂h         ∂L/∂ŷ                                    │
   │      = 2            = 4           = -12                                  │
   │                                                                           │
   │    ∂L/∂w1 = (∂L/∂ŷ) × (∂ŷ/∂h) × (∂h/∂w1)                               │
   │            = (-12)  ×    4    ×    2    = -96                            │
   └─────────────────────────────────────────────────────────────────────────────┘

   下面分别看这三段是怎么算出来的：
```

---

### 第 1 段：$\partial L / \partial \hat{y}$（输出层对 Loss 的敏感度）

```text
           只看这一小段
   ┌──────────────┐    ┌──────────────┐
   │   ŷ          │───→│  L = (ŷ-30)² │
   │   (预测值)    │    │              │
   └──────────────┘    └──────────────┘

    如果 ŷ 从 24 变成 25（增加 1）：
    L = (25 - 30)² = 25（从 36 变成 25）
    变化 = (25 - 36) / (25 - 24) = -11 / 1 = -11
    精确导数（用数学公式） = 2 * (ŷ - 30) = 2 * (24 - 30) = -12
```

---

### 第 2 段：$\partial \hat{y} / \partial h$（隐藏层对输出的敏感度）

```text
           只看这一小段
   ┌──────────────┐    ┌──────────────┐
   │   h          │───→│  ŷ = w2 * h  │
   │              │    │   w2 = 4     │
   └──────────────┘    └──────────────┘

    如果 h 从 6 变成 7（增加 1）：
    ŷ = 4 * 7 = 28（从 24 变成 28）
    变化 = (28 - 24) / (7 - 6) = 4 / 1 = 4
    导数 = w2 = 4
```

---

### 第 3 段：$\partial h / \partial w_1$（权重 w1 对隐藏层的敏感度）

```text
           只看这一小段
   ┌──────┐    ┌──────────────┐
   │      │    │              │
   │ x=2  │───→│  h = w1 * x  │
   │      │    │   x = 2      │
   └──────┘    └──────────────┘

    如果 w1 从 3 变成 4（增加 1）：
    h = 4 * 2 = 8（从 6 变成 8）
    变化 = (8 - 6) / (4 - 3) = 2 / 1 = 2
    导数 = x = 2
```

---

## 第五步：把三段乘起来（链式法则完成）

```text
   ┌─────────────────────────────────────────────────────────────────────────────┐
   │                                                                           │
   │   ∂L        ∂L      ∂ŷ      ∂h                                           │
   │   ──  =    ──   ×   ──   ×   ──                                          │
   │   ∂w1       ∂ŷ      ∂h      ∂w1                                          │
   │                                                                           │
   │          =   (-12)  ×   4    ×   2   =   -96                             │
   │                                                                           │
   └─────────────────────────────────────────────────────────────────────────────┘
```

---

## 完整反向传播图（带所有数值）

```text
   ═════════════════════════════════════════════════════════════════════════════════
                              反 向 传 播 方 向（从右往左）
                                ←──────────  ←──────────  ←──────────
   ┌──────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
   │      │    │              │    │              │    │              │
   │ x=2  │───→│  h = w1 * x  │───→│  ŷ = w2 * h  │───→│  L = (ŷ-30)² │
   │      │    │    w1=3      │    │    w2=4      │    │   = 36       │
   └──────┘    └──────────────┘    └──────────────┘    └──────────────┘
                                        ↑                   ↑
                    ∂h/∂w1 = 2      ∂ŷ/∂h = 4         ∂L/∂ŷ = -12
                    
                    └─────────────────┼───────────────────┘
                                       │
                          ∂L/∂w1 = (-12) × 4 × 2 = -96
                          
   ═════════════════════════════════════════════════════════════════════════════════
```

---

## 反向传播的最终输出（给优化器）

| 参数 | 偏导数（梯度） | 含义 |
|------|---------------|------|
| \( \partial L / \partial w_2 \) | **-36** | w2 增加 → Loss 大幅下降 |
| \( \partial L / \partial w_1 \) | **-96** | w1 增加 → Loss 更大幅下降 |

优化器拿到这两个数字后，会按照“梯度下降”的规则更新参数：
- `w1 = w1 - 学习率 × (-96)` → w1 **增加**
- `w2 = w2 - 学习率 × (-36)` → w2 **增加**

训练几轮后，你会发现网络输出越来越接近 30。

## 一个更直观的生活比喻

> **反向传播 = 工厂质量问题追溯**
>
> 你是一家工厂厂长，发现最终产品良率（Loss）只有 60%。
>
> 1. 你从最后一道工序开始查：发现包装环节（输出层）只要稍微改进，良率就能提升一大截（梯度很大）→ 优先改进这里。
> 2. 但包装环节的负责人说：“我这边没问题，是前面组装环节（隐藏层）送来的零件就有瑕疵。”
> 3. 组装环节说：“是原材料供应（输入层）的精度不够。”
> 4. 你一路往前追溯，把每个环节的“影响系数”乘起来，就找到了**最根本的原因**（比如原材料供应商的某个参数不对）。
>
> 链式法则就是你用来**层层回溯、把最终损失的责任分摊到每一个环节**的数学方法。
