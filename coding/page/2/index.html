    一、什么是 Morris 遍历？ Morris 遍历是一种使用线索二叉树（threaded binary tree）思想的二叉树遍历算法，由某研究者于 1979 年提出。其核心特点包括： 空间复杂度 O(1)：不使用递归栈或队列，只利用二叉树中大量的空闲指针（右指针）来临时记录遍历的后继节点，从而实现遍历。 时间复杂度 O(n)：每个节点最多被访问两次。 Morris 遍历可用于前序、中序、后序遍历，其中经典且常用的是中序遍历。 二、为什么可以用 Morris 遍历？ 普通递归或迭代遍历需要额外的栈保存返回路径，空间复杂度为 O(h)（h 为树高）。Morris 遍历巧妙地利用叶子节点的空右指针，将其指向中序遍历下的后继节点，从而不需要栈就能回到上层节点。访问完该节点后，恢复空指针，保证树的结构不变。 适用条件： 要求 O(1) 空间遍历或修改二叉树。 允许修改树结构。 不能使用递归或栈（递归占用 O(h) 空间）。 三、Morris 遍历的核心思想 1. 将树线性展开 从根节点开始，当前节点 cur。 如果 cur 有左子树： 找到左子树的最右节点 pre（即左子树中一直向右走到底）。 将 cur 的右子树接到 pre 的右边。 将 cur 的左子树移到右边：cur->right = cur->left，cur->left = nullptr。 然后 cur 移动到下一个右节点（cur = cur->right），重复。 // 题目 114 class Solution { public: void flatten(TreeNode* root) { TreeNode* cur = root; while (cur) { if (cur->left) { // 找到左子树的最右节点 TreeNode* pre = cur->left; while (pre->right) pre = pre->right; // 将原右子树接到最右节点 pre->right = cur->right; // 将左子树移到右边 cur->right = cur->left; cur->left = nullptr; } cur = cur->right; } } }; 2. 中序遍历（经典） 核心思想 想象在二叉树中行走，每次遇到左岔路时，希望先走完左边再返回。由于没有栈记录路径，可以在进入左边之前，在左路的最深处（最右边的节点）放置一根“绳子”并将其另一端系在当前节点上。走完左边后，顺着绳子返回，然后解开绳子，继续向右走。这就是 Morris 遍历的本质：利用叶子节点的空右指针作为线索，临时指向后继节点，从而在 O(1) 空间内完成遍历。 ...
