单调栈笔记

  1. 单调栈简介

单调栈是一种特殊的栈结构，栈内元素保持单调递增或单调递减。它常用于求解数组中每个元素左边/右边第一个比它大（或小）的元素位置，时间复杂度 O(n)。

  1. 什么时候使用单调栈？

· 问题中需要为每个元素找到“下一个更大/更小”的元素 例如： · LeetCode 739 每日温度（找下一个更高温度） · LeetCode 496 下一个更大元素 I（找数组中下一个更大元素） · 问题可转化为求每个元素作为最小/最大值时的区间范围 例如： · LeetCode 84 柱状图中最大的矩形（以每个柱子的高度为高，找左右边界） · LeetCode 42 接雨水（每个位置形成凹槽的宽度由左右边界决定） · 需要以 O(n) 时间求出每个元素的左右边界，这些边界由“第一个比它大/小的元素”决定。

典型标志：题目中出现“柱状图”、“矩形面积”、“接雨水”、“温度”、“下一个更大”等字眼，且暴力解法需要 O(n²) 时，可以考虑单调栈。

  1. 核心思想

· 递增栈（栈底到栈顶递增）：用于找左边/右边第一个比当前元素小的位置。 · 递减栈（栈底到栈顶递减）：用于找左边/右边第一个比当前元素大的位置。

在遍历过程中，当遇到破坏单调性的元素时，就弹出栈顶元素，此时可以确定弹出元素的边界（例如，弹出元素右边第一个比它小的就是当前元素，左边第一个比它小的就是栈内下一个元素）。

  1. 例题：LeetCode 84. 柱状图中最大的矩形

问题描述

给定 n 个非负整数表示柱子的高度，每个柱子宽度为 1，求柱状图中能勾勒出的最大矩形面积。

思路

对于每个柱子，以它的高度作为矩形的高，矩形的宽就是它能向左和向右延伸的距离，直到遇到比它矮的柱子。因此我们需要知道每个柱子左边第一个比它矮的位置和右边第一个比它矮的位置。

用单调递增栈（栈内索引对应高度递增）：

· 遍历每个柱子： · 当当前柱子高度小于栈顶柱子高度时，弹出栈顶，计算以栈顶柱子为高的矩形面积： · 右边界 = 当前索引 · 左边界 = 栈内下一个索引（如果栈为空则为 -1） · 宽度 = 右边界 - 左边界 - 1 · 将当前索引压栈。 · 遍历结束后，栈内剩余元素同样处理，右边界 = n（数组长度）。

代码

int largestRectangleArea(vector<int>& heights) {
    stack<int> st; // 存储索引
    int n = heights.size();
    int maxArea = 0;
    
    for (int i = 0; i < n; ++i) {
        while (!st.empty() && heights[i] < heights[st.top()]) {
            int h = heights[st.top()];
            st.pop();
            int left = st.empty() ? -1 : st.top();
            int width = i - left - 1;
            maxArea = max(maxArea, h * width);
        }
        st.push(i);
    }
    
    while (!st.empty()) {
        int h = heights[st.top()];
        st.pop();
        int left = st.empty() ? -1 : st.top();
        int width = n - left - 1;
        maxArea = max(maxArea, h * width);
    }
    return maxArea;
}
  1. 同类题目及思路

题目 核心思路 LeetCode 42. 接雨水 每个位置能接的雨水量 = min(左边最高, 右边最高) - 当前高度。可用单调递减栈维护，当遇到比栈顶高的柱子时，栈顶元素形成凹槽，计算雨水量。 LeetCode 739. 每日温度 找每个元素右边第一个比它大的元素。用单调递减栈，栈内元素等待升温。 LeetCode 496. 下一个更大元素 I 同 739，使用单调递减栈预先处理 nums2 的“下一个更大”映射。 LeetCode 503. 下一个更大元素 II 循环数组的“下一个更大”。将数组复制一遍，用单调栈处理。 LeetCode 901. 股票价格跨度 找当前价格之前连续小于等于它的天数。单调递减栈存（价格，跨度）或索引。 LeetCode 402. 移掉 K 位数字 要得到最小数，需要从左到右移除高位的大数字。单调递增栈保证栈内递增。 LeetCode 316. 去除重复字母 保证字典序最小且保留相对顺序。单调递增栈 + 计数判断。

  1. 总结

· 单调栈适合处理“下一个更大/更小元素”及衍生问题。 · 关键步骤：维护栈的单调性，在弹出时确定边界信息。 · 练习上述题目可以加深理解，做到举一反三。

掌握单调栈后，许多原本需要 O(n²) 的问题都能用 O(n) 解决。
