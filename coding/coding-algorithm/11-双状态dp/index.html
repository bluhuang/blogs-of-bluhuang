双状态 DP（Double-State DP）

1. 一句话定义

同时维护“以当前位置结尾的最优值”和“最差值”，解决因负数（或倒数）导致最优/最差互换的问题。

2. 什么时候用这个套路？

特征说明
运算含乘法（或除法、模）负负得正，大小关系会反转
求最大/最小/最长连续子数组/子序列
状态只依赖前一个位置可用滚动变量 O(1) 空间

典型问法：

  • 最大乘积子数组
  • 乘积为正的最长子数组长度
  • 最大子数组和 不是（加法无反转，单状态DP即可）

3. 与其他套路的对比

套路核心思想适用场景例题
单状态 DP只维护最优值加法、无反转LeetCode 53 最大子数组和
双状态 DP维护最优+最差乘法、有负数LeetCode 152 最大乘积子数组
贪心每步局部最优，不依赖历史区间调度、部分背包、LISLeetCode 300 最长递增子序列（贪心+二分）

4. 模板代码（LeetCode 152，无交换版）

int maxProduct(vector<int>& nums) {
    int maxProd = nums[0], minProd = nums[0], ans = nums[0];
    for (int i = 1; i < nums.size(); i++) {
        int prevMax = maxProd;
        maxProd = max({nums[i], prevMax * nums[i], minProd * nums[i]});
        minProd = min({nums[i], prevMax * nums[i], minProd * nums[i]});
        ans = max(ans, maxProd);
    }
    return ans;
}

为什么需要保存 prevMax？ 因为更新 maxProd 后，原来的 maxProd 就丢失了，而 minProd 的更新还需要用到它。

5. 同类题目

题目状态含义说明
152. 最大乘积子数组最大乘积、最小乘积标准模板
153. 乘积为正的最长子数组长度正长度、负长度计数版双状态
154. 最佳观光组合最大值、当前值变体（非乘积，但类似双状态）

6. 错误理解澄清

  • 遇到0会重置：0 会使 maxProd = minProd = 0，但后续正数会重新开始累积，不会丢失（如 [2,3,0,5,20] 仍能得到 100）。
  • 不是贪心：因为需要依赖前一个最小值，贪心无法仅靠当前局部最优做决策。

7. 记忆口诀

有负数，用乘法，最大最小一起刷。 先保存，再取大，取小也要用到它。
