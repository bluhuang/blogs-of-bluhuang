    背包问题速查笔记（0-1 + 完全）#

    1. 核心区别#

    类型内层循环方向原因记忆口诀
    0-1背包倒序 (j = W ... weight[i])防止重复使用同一个物品0-1 倒
    完全背包正序 (j = weight[i] ... W)允许重复使用同一个物品完全正

    一维 DP 必须外层遍历物品，内层遍历容量（完全背包求排列数时例外，见第4节）

    2. 内层循环方向的原因（深入理解）#

    2.1 0-1 背包倒序的原因#

    用一个物品（重量2，价值10，容量4）模拟：

    • 正序（错误）：
      • j=2 → dp[2]=10
      • j=4 → 用到 dp[2]（刚更新过）→ dp[4]=20 ❌ 一个物品被使用了两次
    • 倒序（正确）：
      • j=4 → 用到 dp[2]（仍为旧值0）→ dp[4]=0
      • j=2 → dp[2]=10 ✅

    结论：倒序保证了 dp[j - weight[i]] 是上一轮（未使用当前物品）的状态。

    2.2 完全背包正序的原因#

    同一个物品（重量2，价值10，容量4）：

    • 正序：
      • j=2 → dp[2]=10
      • j=4 → 用到 dp[2]=10 → dp[4]=20 ✅ 允许重复，正确
    • 倒序（错误）：
      • j=4 → 用到 dp[2]=0 → dp[4]=0
      • j=2 → dp[2]=10 → 最终只能得到10 ❌ 无法重复使用

    结论：正序允许同一物品多次叠加。

    3. 外层必须遍历物品的原因（一维 DP）#

    因为一维数组会覆盖，如果交换成外层容量、内层物品，会出现问题：

    • 0-1 背包：外层容量时，内层物品正序会重复使用物品（同一容量下，多个物品连续更新，相当于可重复）。只有外层物品 + 内层容量倒序才能保证每个物品只被考虑一次。
    • 完全背包：外层物品 + 内层容量正序 得到组合数（顺序无关）；外层容量 + 内层物品正序 得到排列数（顺序有关）。

    一句话记忆：

    0-1 必须外层物品内层倒；完全组合外层物，完全排列外层容。

    4. 两种背包的标准模板#

    4.1 0-1 背包（一维）#

    vector<int> dp(W + 1, 0);
for (int i = 0; i < n; ++i) {                // 外层物品
    for (int j = W; j >= weight[i]; --j) {   // 内层倒序
        dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
    }
}
return dp[W];

    4.2 完全背包（求最大价值 / 组合数）#

    vector<int> dp(W + 1, 0);
for (int i = 0; i < n; ++i) {                // 外层物品
    for (int j = weight[i]; j <= W; ++j) {   // 内层正序
        dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
    }
}
return dp[W];

    4.3 完全背包（求排列数，如零钱兑换 II 的顺序相关方案数）#

    vector<int> dp(W + 1, 0);
dp[0] = 1;
for (int j = 1; j <= W; ++j) {               // 外层容量
    for (int i = 0; i < n; ++i) {            // 内层物品
        if (j >= weight[i]) dp[j] += dp[j - weight[i]];
    }
}
return dp[W];

    5. 常见变形与初始化技巧#

    目标初始化递推
    恰好装满（最大价值）dp[0]=0, 其他 -infmax
    恰好装满（最小数量）dp[0]=0, 其他 +infmin
    求方案数（组合）dp[0]=1, 其他 0dp[j] += dp[j - w[i]]
    求方案数（排列）同上同上，但遍历顺序不同（见4.3）

    7. 总结口诀#

    0-1 倒，完全正；
外层物品是根本；
完全排列换外层；
初始化看要求。

    遇到背包题时：

    1. 判断是 0-1 还是完全
    2. 选模板（外层物品，内层倒/正）
    3. 检查是否需要恰好装满、求方案数
    4. 如果需要顺序相关方案，换成外层容量内层物品
