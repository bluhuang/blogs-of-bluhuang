拓扑排序-Kahn算法与课程表

BluHuang / Coding / 2026年6月2日

我们来深入详细地讲解拓扑排序和Kahn算法，包括它们的原理、实现步骤、代码模板、常见技巧以及应用场景。

一、拓扑排序的基本概念

  1. 定义

拓扑排序（Topological Sorting）是针对有向无环图（DAG）的一种排序算法。它将图中的所有顶点排成一个线性序列，使得对于图中任意一条有向边 u → v，顶点 u 在序列中都出现在顶点 v 之前。

直观理解： 在工程或任务调度中，很多任务之间存在依赖关系（例如：必须先完成A才能开始B）。拓扑排序给出一个可行的任务执行顺序，保证所有依赖都被满足。

  1. 存在条件

· 图必须是有向无环图（DAG）。如果图中有环，则不可能存在拓扑排序（因为环上的任务互相依赖，无法确定先后）。 · 同一个 DAG 可能存在多个不同的拓扑排序。

二、Kahn算法详解

Kahn算法是一种基于贪心策略和BFS思想的拓扑排序实现方法，核心是不断删除入度为0的顶点。

  1. 算法步骤

  2. 计算入度：统计每个顶点的入度（即有多少条边指向该顶点）。

  3. 初始化队列：将所有入度为0的顶点加入队列（这些顶点没有前置依赖，可以直接输出）。

  4. 循环处理： · 从队列中取出一个顶点 u，将其输出（加入拓扑序列）。 · 遍历 u 的所有后继顶点 v（即从 u 出发的边所指向的顶点）。 · 将 v 的入度减1，因为它的一个前置条件 u 已经完成。 · 如果 v 的入度变为0，说明 v 的所有前置都已满足，将其加入队列。

  5. 判断结果： · 如果输出的顶点数等于图中的顶点总数，则拓扑排序成功（图无环）。 · 否则，图中存在环，拓扑排序不存在。

  6. 算法正确性

· 入度为0的顶点没有前置依赖，可以立即输出。 · 删除一个顶点及其出边后，剩下的图仍然是一个DAG，新的入度为0的顶点可以继续输出。 · 如果图中有环，环上的顶点入度永远不会变为0，因此最终输出的顶点数会少于总数。

三、Kahn算法的代码实现（C++模板）

下面是适用于LeetCode 207的Kahn算法实现，包含了常见的建图方式和细节处理。

class Solution {
public:
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        // 邻接表：graph[u] 存储 u 指向的所有顶点
        vector<vector<int>> graph(numCourses);
        // 入度数组
        vector<int> indegree(numCourses, 0);

        // 建图并计算入度
        for (const auto& pre : prerequisites) {
            int a = pre[0]; // 要学 a 必须先学 b
            int b = pre[1];
            graph[b].push_back(a); // b -> a
            indegree[a]++;
        }

        queue<int> q;
        // 将所有入度为0的顶点入队
        for (int i = 0; i < numCourses; i++) {
            if (indegree[i] == 0) {
                q.push(i);
            }
        }

        int count = 0; // 记录已经输出的顶点数
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            count++;
            // 遍历 u 的所有后继
            for (int v : graph[u]) {
                indegree[v]--;
                if (indegree[v] == 0) {
                    q.push(v);
                }
            }
        }
        return count == numCourses; // 如果全部输出，说明无环
    }
};

代码说明：

· 使用 vector<vector> 作为邻接表，节省空间且访问快。 · 入度数组 indegree 记录每个顶点的入度。 · 队列可以用 queue，也可以改用 vector 模拟（如需要按字典序输出时，可能用优先队列）。 · 最后比较 count 和 numCourses，若相等则成功。

四、实现技巧与注意事项

  1. 建图方式

· 如果顶点编号是连续的（如0~n-1），用邻接表（vector<vector>）最方便。 · 如果顶点不是连续的，可以用 unordered_map<int, vector> 存储邻接关系，同时记录入度。 · 注意边的方向：根据问题确定是从先修指向后续，还是反过来。

  1. 处理重复边

· 题目一般不会给出重复边，但如果出现，入度会重复增加，导致逻辑错误。可以在建图前用 set 或 unordered_set 去重，或直接忽略（根据题意，如果重复边意味着相同的依赖多次出现，入度累加可能不合理，但通常题目会保证没有重复边）。

  1. 队列选择

· 普通队列即可满足一般需求。 · 如果需要输出字典序最小的拓扑序列，可以使用优先队列（最小堆）替换普通队列，每次取出编号最小的入度为0的顶点。

  1. 检测环的其他方式

· 如果只需要判断是否有环，DFS染色法也可行（状态0未访问，1访问中，2已完成）。 · 但Kahn算法不仅判环，还能输出拓扑序，更直观。

  1. 空间优化

· 如果图很大，可以使用 vector 的邻接表，避免使用 list 等额外指针开销。 · 入度数组可以用 int 类型，一般足够。

  1. 孤立节点

· 没有依赖的孤立节点（入度为0）也会被加入队列并输出，不影响算法。

五、复杂度分析

· 时间复杂度：O(V + E)，其中 V 是顶点数，E 是边数。因为每个顶点入队出队一次，每条边被访问一次（减入度时）。 · 空间复杂度：O(V + E)，存储邻接表和入度数组。

六、举例说明

考虑一个更复杂的例子： 课程数 = 6，依赖关系：[5,2], [5,0], [4,0], [4,1], [2,3], [3,1] 解释：

· 5 依赖 2 和 0 · 4 依赖 0 和 1 · 2 依赖 3 · 3 依赖 1 · 0 和 1 没有依赖

图结构：

0 → 4 ← 1
↑    ↑    ↑
|    |    |
5 → 2 → 3

边：0→4，1→4，1→3，3→2，2→5，0→5（注意方向：依赖关系是“学a必须先学b”，所以边b→a）

手动模拟Kahn算法：

  1. 初始入度：0:0, 1:0, 2:1(来自3), 3:1(来自1), 4:2(来自0,1), 5:2(来自2,0)
  2. 队列：0,1
  3. 弹出0：count=1，后继4和5的入度减1 → 4入度=1，5入度=1
  4. 弹出1：count=2，后继4和3的入度减1 → 4入度=0（入队4），3入度=0（入队3）
  5. 弹出4：count=3，无后继
  6. 弹出3：count=4，后继2的入度减1 → 2入度=0（入队2）
  7. 弹出2：count=5，后继5的入度减1 → 5入度=0（入队5）
  8. 弹出5：count=6，结束

输出序列：0,1,4,3,2,5（满足依赖关系）

七、常见问题

Q1：拓扑排序的结果唯一吗？

A：不一定。如果图中存在多个入度为0的顶点，选择顺序不同会导致不同的拓扑序列。

Q2：如何判断图中是否有环？

A：Kahn算法最终输出的顶点数小于总顶点数，则存在环。

Q3：如何处理带权图？

A：拓扑排序只关心依赖顺序，不关心权重。权重不影响拓扑序。

Q4：拓扑排序只能用于课程表吗？

A：不，它广泛用于任务调度、编译依赖、数据流分析、项目管理等。

八、扩展：按字典序输出拓扑排序

当要求输出字典序最小的拓扑序列时，只需将普通队列改为优先队列（最小堆）。C++中可用 priority_queue<int, vector, greater>。

priority_queue<int, vector<int>, greater<int>> pq;
// 其余逻辑类似，每次从 pq 中取出最小的入度为0顶点

九、总结

· 拓扑排序：DAG的线性排序，满足依赖关系。 · Kahn算法：通过不断删除入度为0的节点实现拓扑排序，简单高效。 · 实现框架：建图 → 计算入度 → 队列存放入度为0的节点 → BFS更新 → 判断输出数量。 · 技巧：注意入度更新、重复边处理、队列选择等。

掌握这个模板，你可以轻松解决LeetCode 207、210（课程表II）等类似问题。多练习，形成肌肉记忆。
