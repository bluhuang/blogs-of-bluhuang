C++ 实现 int longestValidParentheses(string s) { stack<int> stk; stk.push(-1); int ans = 0; for (int i = 0; i < s.size(); ++i) { if (s[i] == '(') { stk.push(i); } else { stk.pop(); if (stk.empty()) stk.push(i); else ans = max(ans, i - stk.top()); } } return ans; } 关键细节 · 为什么存下标？ 因为需要计算长度（位置差），长度 = 当前下标 − 栈顶下标。 · 为什么栈底预存 -1？ 统一长度计算公式。当有效子串从开头即匹配时（如 "()"），弹栈后栈变空，有了 -1 仍可计算差值。

排列（Permutation）类题型算法复习笔记 1. 题型识别 共同特征 输入通常是一个数组或数字序列。 要求对元素进行重新排列，满足某种顺序（如字典序、下一个排列、所有排列、第 k 个排列等）。 核心考察点往往是字典序（lexicographical order）、回溯、数学（阶乘）。 高频题号一览 题号 题目 一句话概括 31 Next Permutation 找字典序的下一个更大排列 46 Permutations 无重复元素的全排列 47 Permutations II 有重复元素的全排列（去重） 60 Permutation Sequence 求 1~n 的第 k 个排列 556 Next Greater Element III 正整数版本的下一个排列（31 的变体） 526 Beautiful Arrangement 计数符合特殊规则的排列（回溯/DP） 667 Beautiful Arrangement II 构造一个特殊差异数组（数学构造） 2. 核心解题套路总结：下一个排列（31 题） 三步法（经典字典序算法） 从右向左找第一个下降点 i 找到第一对相邻的 nums[i] < nums[i+1]，记下较小数的位置 i。 如果找不到，说明整个数组是降序，已经是最后一个排列，直接反转整个数组。

最大堆与最小堆

1. 什么是堆？ 堆（Heap）是一种特殊的完全二叉树，通常用数组存储。 最大堆：每个父节点的值 大于等于 其子节点的值，堆顶为最大值。 最小堆：每个父节点的值 小于等于 其子节点的值，堆顶为最小值。 堆的核心操作（插入、删除）时间复杂度均为 O(log n)，获取极值为 O(1)。
