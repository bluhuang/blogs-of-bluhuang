环形链表与隐式环形链表

BluHuang / Coding / 2026年6月2日

环形链表题型笔记

一、题型识别：环形链表

环形链表问题有三个层次：

层次题目要求
判断有无环141. 环形链表返回 true/false
找环的入口142. 环形链表 II返回入口节点
隐式环形链表287. 寻找重复数数组模拟链表，找环入口

核心特征：

  • 一个节点通过 next 指针（或映射规则）指向下一个节点
  • 如果存在环，快慢指针一定相遇
  • 从起点到环入口的距离 = 从相遇点绕回入口的距离

二、141. 环形链表（判断有无环）

题目要求

给定一个链表，判断链表中是否有环。

思路

快指针每次走两步，慢指针每次走一步。如果存在环，快指针一定会在环内追上慢指针。

为什么快慢指针一定相遇？

快指针比慢指针速度快 1 步/次。当慢指针进入环后，快指针已经在环内。每移动一次，快指针和慢指针的距离缩短 1。因为环的长度有限，快指针一定会从后面追上慢指针。

反直觉的一点：快指针可能跳过慢指针吗？ 不会。因为每次只差 1 步，快指针要么在慢指针后面（距离 -1），要么重合（距离 0），要么超过（距离 +1）。如果超过，下一步慢指针走 1 步，快指针走 2 步，它们刚好交换位置，不会跳过。最终必然在某点相遇。

如果无环呢？

快指针走到 nullptr（或 fast->next == nullptr），循环结束。

代码

bool hasCycle(ListNode *head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}

三、142. 环形链表 II（找环的入口）

题目要求

给定一个链表，返回环的入口节点。如果无环，返回 nullptr。

思路：两步走

第一步：找相遇点 和 141 一样，快慢指针找到相遇点。

第二步：找入口

  • 一个指针回到起点 head
  • 另一个指针留在相遇点
  • 两个指针每次都只走一步
  • 再次相遇的位置就是环的入口

为什么这样能找到入口？

设：

  • 起点到入口距离 = A
  • 入口到相遇点距离 = B

第一阶段，慢指针走了 A + B 步。快指针速度是慢指针两倍，走了 2(A + B) 步。

快指针比慢指针多走了 A + B 步，这多走的部分都是在环里绕圈。换句话说，快指针在环内多走了 A + B 步，然后正好比慢指针领先了 B 步的位置。

第二阶段，慢指针回到起点走 A 步到入口。快指针从相遇点出发，也走 A 步。因为从相遇点再走 A 步，刚好绕回入口。

所以两人同时到达入口。

代码

ListNode *detectCycle(ListNode *head) {
    ListNode *slow = head, *fast = head;
    
    // 第一步：找相遇点
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            // 第二步：找入口
            slow = head;
            while (slow != fast) {
                slow = slow->next;
                fast = fast->next;  // 都走一步
            }
            return slow;
        }
    }
    return nullptr;  // 无环
}

四、287. 寻找重复数（隐式环形链表）

题目要求

给定 n + 1 个整数，值在 [1, n] 内。只有一个数字重复。找出该数字。

约束：

  • 不能修改原数组
  • O(1) 额外空间
  • 时间小于 O(n²)

为什么能转化成环形链表？

把数组下标看成节点，nums[i] 看成节点 i 的 next 指针：

i → nums[i]

关键：数组有 n+1 个位置，值在 1~n 内，所以 nums[i] 永远不会越界。从任意位置出发，可以一直走下去。

为什么一定有环？ 抽屉原理：n+1 个物品放进 n 个抽屉，至少一个抽屉有 2 个物品。

  • 物品 = 数组中的值
  • 抽屉 = 数字 1~n

一个数字出现两次，意味着两个节点指向同一个目标，形成环。

重复数字 = 环的入口。

转化示例

nums = [1, 3, 4, 2, 2]

下标: 0 → 1 → 3 → 2 → 4
                  ↑   ↓
                  ← ← ←
  • 节点 3 指向节点 2
  • 节点 4 也指向节点 2
  • 进入节点 2 后，就在 2 → 4 → 2 → 4 里死循环

环的入口 = 2 = 重复数字。

与 142 的对比

142. 环形链表 II287. 寻找重复数
数据结构显式链表数组模拟的隐式链表
next 指针node->nextnums[index]
起点headnums[0]
走一步node = node->nextindex = nums[index]
走两步node = node->next->nextindex = nums[nums[index]]
环入口入环节点重复数字

为什么不需要判断无环？

因为题目保证有一个数字重复出现两次，所以必然有环，不需要判断无环。

如果每个数字恰好出现一次，值域 [1, n] 无法满足 n+1 个数，所以必然有重复，必然有环。

代码

int findDuplicate(vector<int>& nums) {
    // 起点：nums[0] 作为头节点
    int slow = nums[0];
    int fast = nums[0];
    
    // 第一步：找相遇点
    // 用 do-while，因为初始 slow == fast
    do {
        slow = nums[slow];           // 走一步
        fast = nums[nums[fast]];     // 走两步
    } while (slow != fast);
    
    // 第二步：找环的入口
    slow = nums[0];                  // 回到起点
    while (slow != fast) {
        slow = nums[slow];           // 都走一步
        fast = nums[fast];
    }
    return slow;                     // 入口 = 重复数字
}

易错点

易错点正确写法
第一阶段循环do-while，不是 while
走两步nums[nums[fast]]，不是 nums[fast + 1]
第二阶段回到起点slow = nums[0]，不是 slow = 0
第二阶段速度两个都走一步，fast 不再走两步
返回值返回 slow，不是 nums[slow]

五、举一反三：快乐数（LeetCode 202）

题目要求

判断一个数 n 是不是快乐数：

  • 每次用各位数字的平方和替换当前数
  • 如果最终变成 1，就是快乐数
  • 如果无限循环且不为 1，就不是

为什么也是环形链表？

把每个数看成一个节点，getNext(n) 就是它的 next 指针。如果陷入循环，就形成环。判断环的入口是不是 1 即可。

int getNext(int n) {
    int sum = 0;
    while (n) {
        int d = n % 10;
        sum += d * d;
        n /= 10;
    }
    return sum;
}

bool isHappy(int n) {
    int slow = n, fast = getNext(n);
    while (fast != 1 && slow != fast) {
        slow = getNext(slow);
        fast = getNext(getNext(fast));
    }
    return fast == 1;
}

六、总结

题目核心解法
141. 环形链表判断有无环快慢指针，相遇=有环
142. 环形链表 II找环的入口相遇后，慢回起点同速走
287. 寻找重复数数组隐式环同 142，把 next 换成 nums[i]
202. 快乐数数字变换环同 141/142，找入口是否为 1

记忆口诀：

“快慢指针找相遇，慢回起点同步走，再次相遇是入口。”
