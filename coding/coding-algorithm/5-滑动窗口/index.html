滑动窗口

BluHuang / Coding / 2026年6月2日

滑动窗口题型总结笔记

1. 题型特征与适用条件

什么时候使用滑动窗口？
滑动窗口适用于解决 子串/子数组 问题，通常需要找到满足某种条件的最短、最长或固定长度的连续区间。常见特征：

  • 输入是线性结构（字符串或数组）
  • 问题涉及连续区间，且需要动态调整边界
  • 条件通常与元素计数、和、乘积、字符种类等有关
  • 往往需要在线性时间内求解

关键点：

  • 何时扩大窗口：右指针移动，将新元素加入窗口。
  • 何时收缩窗口：当窗口满足题目条件时，尝试收缩左边界以寻找更优解（如最小长度），或当窗口不满足条件时收缩（如求最长无重复子串）。

典型场景：最小覆盖子串、无重复字符的最长子串、长度最小的子数组、字符串排列、字母异位词、最多包含 K 个不同字符的子串、替换后的最长重复字符等。

2. 为什么可以用滑动窗口？

滑动窗口本质是 双指针技术 的一种，它利用窗口内数据的单调性或条件的变化，通过移动左右指针来遍历所有可能的连续子区间，同时避免重复计算。核心思想：

  • 右指针负责 扩展窗口，纳入新元素
  • 左指针负责 收缩窗口，当窗口满足条件时尝试缩小以寻找更优解
  • 通过维护窗口内的状态（如哈希表、计数等），在 O(1) 时间内判断是否满足条件

由于每个元素最多被左右指针各访问一次，时间复杂度为 O(n)。

3. 通用解题模板（基于 LeetCode 76 最小覆盖子串）

题目描述：给定字符串 s 和 t，在 s 中找出包含 t 所有字符的最短子串。

void slidingWindow(string s, string t) {
    unordered_map<char, int> need, window;
    for (char c : t) need[c]++;          // 记录目标需求
    int left = 0, right = 0;
    int valid = 0;                        // 已满足的字符种类数
    while (right < s.size()) {
        char c = s[right];
        right++;                          // 扩大窗口
        
        // 窗口内数据更新
        if (need.count(c)) {
            window[c]++;
            if (window[c] == need[c])
                valid++;
        }
        
        // 判断左侧窗口是否需要收缩
        while (valid == need.size()) {    // 满足条件时收缩
            // 更新最优解（如记录最小窗口）
            
            char d = s[left];
            left++;                       // 收缩窗口
            
            // 窗口内数据更新
            if (need.count(d)) {
                if (window[d] == need[d])
                    valid--;
                window[d]--;
            }
        }
    }
}

4. 关键概念解析

4.1 need 哈希表

  • 记录目标字符串中每个字符的 需求次数。
  • 例如 t = "AABC" → need['A']=2, need['B']=1, need['C']=1。
  • 它的 size() 表示需要满足的字符种类数。

4.2 window 哈希表

  • 记录当前窗口内每个字符的 实际出现次数。

4.3 valid 变量

  • 统计 当前窗口中已经刚好满足 need 数量要求的字符种类数。
  • 更新规则：
    • 右指针移入字符 c：若 window[c] == need[c]，则 valid++。
    • 左指针移出字符 d：若 window[d] == need[d]，则 valid--。
  • 当 valid == need.size() 时，窗口已完全覆盖目标字符串的所有需求。

为什么用 valid 而不是直接比较两个哈希表？
因为每次检查都需要遍历 need，而用 valid 可以在 O(1) 时间内判断是否满足条件，提高效率。

5. LeetCode 经典题型（含完整代码，已逐题验证）

5.1 LeetCode 76. 最小覆盖子串

题目描述：给定字符串 s 和 t，返回 s 中涵盖 t 所有字符的最小子串。如果不存在，返回空字符串。

思路：滑动窗口 + need/window/valid。右指针不断扩展，当窗口满足条件时，收缩左边界并更新最小长度和起始位置。

class Solution {
public:
    string minWindow(string s, string t) {
        unordered_map<char, int> need, window;
        for (char c : t) need[c]++;
        
        int left = 0, right = 0;
        int valid = 0;
        int start = 0, minLen = INT_MAX;
        
        while (right < s.size()) {
            char c = s[right];
            right++;
            if (need.count(c)) {
                window[c]++;
                if (window[c] == need[c]) valid++;
            }
            
            while (valid == need.size()) {
                if (right - left < minLen) {
                    start = left;
                    minLen = right - left;
                }
                char d = s[left];
                left++;
                if (need.count(d)) {
                    if (window[d] == need[d]) valid--;
                    window[d]--;
                }
            }
        }
        return minLen == INT_MAX ? "" : s.substr(start, minLen);
    }
};

5.2 LeetCode 3. 无重复字符的最长子串

题目描述：给定一个字符串 s，找出其中不含有重复字符的最长子串的长度。

思路：滑动窗口 + 哈希表记录字符出现次数。右指针扩展，当出现重复字符时，收缩左边界直到重复消失。

class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        unordered_map<char, int> window;
        int left = 0, right = 0;
        int maxLen = 0;
        
        while (right < s.size()) {
            char c = s[right];
            right++;
            window[c]++;
            
            while (window[c] > 1) {
                char d = s[left];
                left++;
                window[d]--;
            }
            maxLen = max(maxLen, right - left);
        }
        return maxLen;
    }
};

5.3 LeetCode 209. 长度最小的子数组

题目描述：给定一个含有 n 个正整数的数组和一个正整数 target，找出该数组中满足其和 ≥ target 的长度最小的连续子数组，并返回其长度。如果不存在，返回 0。

思路：滑动窗口维护窗口和。右指针扩展累加，当和 ≥ target 时，收缩左边界并更新最小长度。

class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int left = 0, right = 0;
        int sum = 0, minLen = INT_MAX;
        
        while (right < nums.size()) {
            sum += nums[right];
            right++;
            
            while (sum >= target) {
                minLen = min(minLen, right - left);
                sum -= nums[left];
                left++;
            }
        }
        return minLen == INT_MAX ? 0 : minLen;
    }
};

5.4 LeetCode 567. 字符串的排列

题目描述：给定两个字符串 s1 和 s2，写一个函数来判断 s2 是否包含 s1 的排列。即 s1 的某个排列是 s2 的子串。

思路：固定窗口大小为 s1.size()，滑动窗口 + need/window/valid。当窗口长度等于 s1 长度时判断 valid，然后收缩左边界继续滑动。

class Solution {
public:
    bool checkInclusion(string s1, string s2) {
        unordered_map<char, int> need, window;
        for (char c : s1) need[c]++;
        
        int left = 0, right = 0;
        int valid = 0;
        
        while (right < s2.size()) {
            char c = s2[right];
            right++;
            if (need.count(c)) {
                window[c]++;
                if (window[c] == need[c]) valid++;
            }
            
            while (right - left >= s1.size()) {
                if (valid == need.size()) return true;
                char d = s2[left];
                left++;
                if (need.count(d)) {
                    if (window[d] == need[d]) valid--;
                    window[d]--;
                }
            }
        }
        return false;
    }
};

5.5 LeetCode 438. 找到字符串中所有字母异位词

题目描述：给定两个字符串 s 和 p，找到 s 中所有 p 的异位词的子串，返回这些子串的起始索引。异位词指字母相同但排列不同的字符串。

思路：与 567 完全一致，只是将返回 true 改为记录起始索引到 res。

class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        unordered_map<char, int> need, window;
        for (char c : p) need[c]++;
        
        int left = 0, right = 0;
        int valid = 0;
        vector<int> res;
        
        while (right < s.size()) {
            char c = s[right];
            right++;
            if (need.count(c)) {
                window[c]++;
                if (window[c] == need[c]) valid++;
            }
            
            while (right - left >= p.size()) {
                if (valid == need.size()) {
                    res.push_back(left);  // 记录起始索引
                }
                char d = s[left];
                left++;
                if (need.count(d)) {
                    if (window[d] == need[d]) valid--;
                    window[d]--;
                }
            }
        }
        return res;
    }
};

5.6 LeetCode 340. 至多包含 K 个不同字符的最长子串

题目描述：给定一个字符串 s 和一个整数 k，找出至多包含 k 个不同字符的最长子串的长度。

思路：滑动窗口 + 哈希表记录字符频次。当不同字符数 > k 时，收缩左边界。

class Solution {
public:
    int lengthOfLongestSubstringKDistinct(string s, int k) {
        unordered_map<char, int> window;
        int left = 0, right = 0;
        int maxLen = 0;
        
        while (right < s.size()) {
            char c = s[right];
            right++;
            window[c]++;
            
            while (window.size() > k) {
                char d = s[left];
                left++;
                window[d]--;
                if (window[d] == 0) window.erase(d);
            }
            maxLen = max(maxLen, right - left);
        }
        return maxLen;
    }
};

5.7 LeetCode 424. 替换后的最长重复字符

题目描述：给定一个字符串 s 和一个整数 k，你可以将字符串中的任意字符替换为其他字符，最多执行 k 次。求替换后包含相同字母的最长子串的长度。

核心思路（通俗解释）：
我们想要一个全部由同一个字母组成的最长子串。在任意窗口内，要把所有字符变成同一个字母，需要替换的次数 = 窗口长度 - 窗口内出现次数最多的那个字母的频次。
例如窗口 "AABBC"，长度 5，最多字母是 'A' 出现了 2 次，那么把其他 3 个字母变成 'A' 需要 3 次替换。只要这个替换次数 ≤ k，这个窗口就可以通过不超过 k 次替换变成全部相同字母。
因此我们维护窗口内最大频次 maxCount，当 窗口长度 - maxCount > k 时，说明当前窗口无法通过 k 次替换变成全相同，需要收缩左边界。

注意：maxCount 在收缩时可能不会立即减小，但这不影响结果正确性，因为我们只需要在满足条件时记录最大窗口长度。

class Solution {
public:
    int characterReplacement(string s, int k) {
        vector<int> count(26, 0);
        int left = 0, right = 0;
        int maxCount = 0, maxLen = 0;
        
        while (right < s.size()) {
            char c = s[right];
            right++;
            count[c - 'A']++;
            maxCount = max(maxCount, count[c - 'A']);
            
            // 判断是否需要收缩：窗口长度 - 最多频次 > k 则无法满足
            while (right - left - maxCount > k) {
                char d = s[left];
                left++;
                count[d - 'A']--;
                // 注意：maxCount 不用更新，因为收缩不会增加 maxCount
            }
            maxLen = max(maxLen, right - left);
        }
        return maxLen;
    }
};

5.8 LeetCode 992. K 个不同整数的子数组

题目描述：给定一个正整数数组 nums 和一个整数 k，返回 nums 中「恰好由 k 个不同整数组成」的连续子数组的个数。

为什么不能直接找恰好 K 个？
滑动窗口在收缩时，我们通常用 while (window.size() > k) 来维持窗口内不同元素个数 ≤ k。但是如果要维护 恰好 k 个，当窗口内不同元素个数变为 k 时，我们无法判断应该收缩左边界还是继续扩展右边界，因为扩展可能会变成 k+1，收缩可能会变成 k-1。窗口状态的变化没有单调性，无法用简单的双指针直接维护“恰好等于”。

解决方案：转换思路
恰好 K 个不同整数的子数组个数 = 最多 K 个不同整数的子数组个数 - 最多 K-1 个不同整数的子数组个数。
这两个“最多”问题都可以用标准滑动窗口轻松解决。每次右指针移动后，以当前右指针结尾的满足条件的子数组个数恰好等于窗口长度（因为左指针可以取 [left, right-1] 中任意位置作为起点，窗口内不同元素个数都 ≤ K）。

class Solution {
public:
    int subarraysWithKDistinct(vector<int>& nums, int k) {
        return atMostK(nums, k) - atMostK(nums, k - 1);
    }
    
    // 计算最多包含 k 个不同整数的子数组个数
    int atMostK(vector<int>& nums, int k) {
        unordered_map<int, int> window;
        int left = 0, right = 0;
        int count = 0;
        
        while (right < nums.size()) {
            int c = nums[right];
            right++;
            window[c]++;
            
            while (window.size() > k) {
                int d = nums[left];
                left++;
                window[d]--;
                if (window[d] == 0) window.erase(d);
            }
            // 以 right-1 结尾的、满足条件的子数组个数 = 窗口长度
            count += right - left;
        }
        return count;
    }
};

5.9 LeetCode 713. 乘积小于 K 的子数组

题目描述：给定一个正整数数组 nums 和一个整数 k，返回 nums 中乘积小于 k 的连续子数组的个数。

思路：滑动窗口维护窗口乘积。右指针扩展累乘，当乘积 ≥ k 时收缩左边界。每次右指针移动后，以当前右指针结尾的满足条件的子数组个数 = 窗口长度。

class Solution {
public:
    int numSubarrayProductLessThanK(vector<int>& nums, int k) {
        if (k <= 1) return 0;
        int left = 0, right = 0;
        int prod = 1, count = 0;
        
        while (right < nums.size()) {
            prod *= nums[right];
            right++;
            
            while (prod >= k) {
                prod /= nums[left];
                left++;
            }
            // 以 right-1 结尾的、乘积小于 k 的子数组个数
            count += right - left;
        }
        return count;
    }
};

7. 总结

滑动窗口是一种高效处理连续子区间问题的技巧，核心在于维护窗口状态并动态调整边界。通过 need、window 和 valid 的配合，可以灵活应对各种计数类条件。掌握模板后，只需根据题目要求调整收缩时机和更新逻辑，即可轻松解决一大类问题。
