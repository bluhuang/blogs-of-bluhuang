双指针解决去重排列组合问题

一、题型识别

这类题属于 “N 数之和”双指针题型，核心特征是：

特征说明
输入是无序数组必须先排序
要求返回所有不重复的组合[a,b] 和 [b,a] 视为同一个
组合顺序不重要只关心元素集合，不关心排列顺序
暴力枚举会超时必须用双指针压缩搜索空间

一句话识别：

“找所有固定数量、不考虑顺序、需要去重的组合”

二、为什么要排序 + 双指针？

排序的作用

  • 让相同元素相邻，去重只需判断 nums[i] == nums[i-1]
  • 让双指针可以根据和的大小决定移动方向（和太小左指针右移，和太大右指针左移）

双指针的作用

  • 将 O(n³) 降到 O(n²)（三数之和）
  • 去重极其简洁：找到解后跳过所有与当前 left 或 right 相同的值

三、核心模板：三数之和

vector<vector<int>> threeSum(vector<int>& nums) {
    vector<vector<int>> res;
    int n = nums.size();
    if (n < 3) return res;
    
    sort(nums.begin(), nums.end());          // ① 排序（去重前提）
    
    for (int i = 0; i < n - 2; ++i) {
        if (i > 0 && nums[i] == nums[i-1])   // ② 跳过重复的第一个数
            continue;
        
        int left = i + 1, right = n - 1;     // ③ 双指针
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum == 0) {
                res.push_back({nums[i], nums[left], nums[right]});
                // ④ 跳过重复的 left 和 right
                while (left < right && nums[left] == nums[left+1]) left++;
                while (left < right && nums[right] == nums[right-1]) right--;
                left++;
                right--;
            } else if (sum < 0) {
                left++;
            } else {
                right--;
            }
        }
    }
    return res;
}

四、去重三法则（最易错的地方）

去重对象代码时机
第一个数if (i > 0 && nums[i] == nums[i-1]) continue;每次固定第一个数之前
第二个数while (nums[left] == nums[left+1]) left++;找到解后，移动 left 之前
第三个数while (nums[right] == nums[right-1]) right--;找到解后，移动 right 之前

去重原理：排序后相同元素相邻，只需要跳过所有与“刚用过”的值相同的元素。

五、同类题目一览

题号题目与模板的差异
1两数之和只找一个解，用哈希表 O(n)，也可排序+双指针
15三数之和标准模板，固定一个 + 双指针
18四数之和固定两个 + 双指针，注意 long 防溢出
16最接近的三数之和同模板，改判断条件为 abs(sum - target) 最小
259较小的三数之和统计个数，sum < target 时计数 += right - left

六、什么时候用双指针，什么时候用回溯？

这是新手最容易混淆的地方。关键看两点：

判断流程图

题目要求找所有组合？
├── 组合数量固定（2个、3个、4个）？
│   └── 顺序不重要 + 需要去重？
│       └── ✅ 用「排序 + 双指针」
│          例题：15, 18, 16
│
└── 组合数量不固定？或考虑顺序？或不能排序？
    └── ✅ 用「回溯」
        例题：39(可重复选), 40(不可重复), 46(排列)

对比表

对比维度排序 + 双指针回溯
典型题15, 18, 1639, 40, 46, 47
组合数量固定（2/3/4个）不固定
顺序是否重要不重要，去重重要（排列）或不重要（组合）
能否排序能能或不能
元素能否重复使用不能能或不能
时间复杂度O(n²)（三数之和）O(n³) 或更高
去重难度简单（排序后跳过相邻）较难（需同层去重）

七、记忆口诀

“定数无序用双指，变数有序用回溯。 排序固定前几个，剩下两个左右缩。 去重全看前一个，相等就跳不啰嗦。”

八、快速自查清单

拿到一道组合类题目，依次问自己：

  • 组合数量固定吗？（是→双指针，否→回溯）
  • 顺序重要吗？（不重要→双指针，重要→回溯）
  • 需要去重吗？（是→排序是前提）
  • 固定层去重写了吗？（nums[i] == nums[i-1]）
  • 找到解后 left 和 right 去重写了吗？（两个 while）

复习建议：把三数之和的模板手写三遍，重点练去重逻辑。然后做四数之和验证能否独立写出。
