连续子数组极值问题

BluHuang / Coding / 2026年6月2日

1 题型特征

  • 数组：一维数组、环（变种）、可重复等
  • 目标：求连续子数组的极值（和、乘积、长度）
  • 约束：子数组是连续的（子序列不要求连续，相对顺序一致即可）

2 解题套路总结a

2.1 一维数组 连续子数组 问题

解题思路

  • 动态规划
    • Kadane算法：用于求解最大子数组和的动态规划算法，它通过遍历数组，维护以当前元素结尾的最大子数组和，并不断更新全局最大值，从而在O(n)时间内得到结果。
  • 前缀和 + 哈希表
  • 滑动窗口（适合有长度或限制）

核心代码

Kadane 算法（最大子数组和）

int maxSubArray(vector<int>& nums) {
    int maxCur = nums[0]; // 以当前元素结尾的最大和
    int maxGlobal = nums[0]; // 全局最大和
    for (int i = 1; i < nums.size(); ++i) {
        // 如果前面的和是负数，就抛弃，从当前元素重新开始
        maxCur = max(nums[i], maxCur + nums[i]);
        maxGlobal = max(maxGlobal, maxCur);
    }
    return maxGlobal;
}

前缀和 + 哈希表（和为 K 的子数组）

int subarraySum(vector<int>& nums, int k) {
    unordered_map<int, int> prefixCount; // 前缀和 -> 出现次数
    prefixCount[0] = 1; // 前缀和为0的出现一次（空数组）
    int sum = 0, count = 0;
    for (int num : nums) {
        sum += num;
        // 如果存在前缀和等于 sum - k，则中间这段子数组和为 k
        if (prefixCount.count(sum - k)) {
            count += prefixCount[sum - k];
        }
        prefixCount[sum]++;
    }
    return count;
}

滑动窗口（长度最小的子数组）

int minSubArrayLen(int target, vector<int>& nums) {
    int left = 0, sum = 0, minLen = INT_MAX;
    for (int right = 0; right < nums.size(); ++right) {
        sum += nums[right];
        // 窗口和满足条件时，尝试收缩左边界
        while (sum >= target) {
            minLen = min(minLen, right - left + 1);
            sum -= nums[left++];
        }
    }
    return minLen == INT_MAX ? 0 : minLen;
}

2.2 环形数组

拆分为两种情况，转化为普通数组问题

  • 1. 最大子数组不在环上：即普通的最大子数组和，可以用 Kadane 算法求解。
  • 2. 最大子数组跨越环：转换为 -> 整个数组的和 减去 中间一段不包含的部分（总和减去最小子数组和）
  • 关键点：需要排除子数组为空的情况

核心代码

int maxSubarraySumCircular(vector<int>& nums) {
    int maxCur = nums[0], maxGlobal = nums[0];
    int minCur = nums[0], minGlobal = nums[0];
    int total = nums[0];
    
    for (int i = 1; i < nums.size(); ++i) {
        maxCur = max(nums[i], maxCur + nums[i]);
        maxGlobal = max(maxGlobal, maxCur);
        
        minCur = min(nums[i], minCur + nums[i]);
        minGlobal = min(minGlobal, minCur);
        
        total += nums[i];
    }
    
    // 情况2：总和减去最小子数组和（跨越边界）
    int maxCircular = total - minGlobal;
    
    // 【疑问解答1】
    // 问：为什么 maxGlobal < 0 时直接返回 maxGlobal，而不是和 maxCircular 取最大？
    // 答：当所有元素都为负数时，maxGlobal 是数组中的最大单个元素（负数）。
    //    而此时 minGlobal 会等于 total（因为整个数组都是负数，最小子数组和就是整个数组的和），
    //    导致 maxCircular = total - minGlobal = 0。
    //    0 代表空子数组（一个元素都不选），但题目要求子数组必须至少包含一个元素。
    //    因此，全负数情况下必须排除空子数组，直接返回 maxGlobal。
    // 问：如何排除空子数组？
    // 答：正是通过 `if (maxGlobal < 0) return maxGlobal;` 这一行。
    //    当数组中存在非负数时，maxGlobal 至少为0，不会进入这个分支，此时 maxCircular 有效。
    if (maxGlobal < 0) return maxGlobal;
    
    return max(maxGlobal, maxCircular);
}

2.3 重复拼接数组（如k次）

题目要求

  • LeetCode 1191. K 次串联后最大子数组和：给定一个整数数组 arr 和一个整数 k，将数组重复 k 次得到一个新数组，返回新数组的最大子数组和。由于答案可能很大，需对 10^9 + 7 取模。

  • 重复数组问题：关键是将无限长数组分解为“一个数组内”和“跨越两个数组”两种情况，再利用数组总和的正负决定是否添加中间完整数组。

  • 常用技巧：

    • 最大子数组和 → Kadane
    • 最大前缀和、最大后缀和 → 简单累加取最大
    • 分类讨论 k 的取值

  • 边界情况：全负数、总和为负、k=1 等。

  • 最大前缀和：从数组开头开始，累加并记录过程中的最大值（不一定取到末尾）。

  • 最大后缀和：从数组末尾开始，累加并记录过程中的最大值。

解题思路：

  1. 如果 k == 1：直接求原数组的最大子数组和（Kadane 算法）。
  2. 如果 k >= 2：
    • 最大子数组可能在一个数组内
    • 也可能跨越两个数组的边界：最大后缀和 + 最大前缀和 %% 取原数组的最大后缀和（从某个位置到末尾）加上下一个数组的最大前缀和（从开头到某个位置） %%
    • 如果原数组的总和sum是正数, 那么最大和 = 最大后缀和 + sum * (k - 2) + 最大前缀和
    • 如果原数组的综合sum <= 0, 那么最大和 = MAX( 单数组内最大和, 跨越2个数组的最大和）
  3. 特殊情况：
    • 如果所有元素都是负数，那么最大子数组就是单个最大元素（Kadane 会得到这个值）

核心代码

const int MOD = 1e9 + 7;

int kConcatenationMaxSum(vector<int>& arr, int k) {
    int n = arr.size();
    long long total = 0;
    for (int x : arr) total += x;
    
    // 1. 单个数组内的最大子数组和（Kadane）
    long long maxOne = kadane(arr);
    if (k == 1) return maxOne % MOD;
    
    // 2. 计算最大前缀和
    long long maxPrefix = 0, prefix = 0;
    for (int i = 0; i < n; ++i) {
        prefix += arr[i];
        maxPrefix = max(maxPrefix, prefix);
    }
    
    // 3. 计算最大后缀和
    long long maxSuffix = 0, suffix = 0;
    for (int i = n - 1; i >= 0; --i) {
        suffix += arr[i];
        maxSuffix = max(maxSuffix, suffix);
    }
    
    // 4. 跨越两个数组的最大和
    long long maxTwo = maxPrefix + maxSuffix;
    
    // 5. 根据总和正负分类讨论
    long long candidate;
    if (total > 0) {
        candidate = maxTwo + (k - 2) * total;
    } else {
        candidate = maxTwo;
    }
    
    return max(maxOne, candidate) % MOD;
}

// Kadane 算法（返回最大子数组和）
long long kadane(vector<int>& arr) {
    long long maxCur = arr[0], maxGlobal = arr[0];
    for (int i = 1; i < arr.size(); ++i) {
        maxCur = max((long long)arr[i], maxCur + arr[i]);
        maxGlobal = max(maxGlobal, maxCur);
    }
    return maxGlobal;
}

2.4 乘积问题，注意负负得正，同时维护最大和最小

核心思路

由于负数乘负数得正数，所以当前最大值可能由之前的最大值乘正数得到，也可能由之前的最小值（负数）乘当前负数得到。因此，我们需要同时维护以当前位置结尾的最大乘积和最小乘积。

动态规划定义

  • maxProd[i]：以 nums[i] 结尾的子数组的最大乘积。
  • minProd[i]：以 nums[i] 结尾的子数组的最小乘积。

核心代码

int maxProduct(vector<int>& nums) {
    int maxCur = nums[0]; // 以当前元素结尾的最大乘积
    int minCur = nums[0]; // 以当前元素结尾的最小乘积
    int maxGlobal = nums[0];
    
    for (int i = 1; i < nums.size(); ++i) {
        // 因为要同时用到上一轮的 maxCur 和 minCur，所以先暂存
        int tempMax = maxCur, tempMin = minCur;
        
        // 三种可能：当前元素单独成段、乘上一轮最大值、乘上一轮最小值（负负得正）
        maxCur = max({nums[i], tempMax * nums[i], tempMin * nums[i]});
        minCur = min({nums[i], tempMax * nums[i], tempMin * nums[i]});
        
        maxGlobal = max(maxGlobal, maxCur);
    }
    return maxGlobal;
}

3 题目列表

题目特点思路描述与解法代码
LeetCode 53. 最大子数组和基础版思路：标准 Kadane 算法。维护以当前元素结尾的最大和，如果前面的和是负数就抛弃。

代码：maxCur = max(nums[i], maxCur + nums[i]); maxGlobal = max(maxGlobal, maxCur);
LeetCode 918. 环形子数组的最大和环形思路：拆分为两种情况：① 普通最大子数组和（Kadane）；② 跨越边界的情况 = 总和 - 最小子数组和。取两者最大值。注意全负数时直接返回 Kadane 结果（排除空子数组）。

代码：maxCircular = total - minGlobal; return maxGlobal < 0 ? maxGlobal : max(maxGlobal, maxCircular);
LeetCode 1191. K 次串联后最大子数组和数组重复k次思路：分情况讨论。k=1 时直接用 Kadane；k≥2 时，计算最大前缀和、最大后缀和、总和。若总和>0，答案为 maxSuffix + total*(k-2) + maxPrefix；否则为 max(maxOne, maxSuffix + maxPrefix)。结果对 1e9+7 取模。

代码：见 2.3 节核心代码。
LeetCode 152. 乘积最大子数组乘积（有负负得正）思路：同时维护以当前位置结尾的最大乘积和最小乘积。因为负数乘负数可能变成最大值。每轮更新时，候选值包括：当前元素本身、当前元素乘上一轮最大值、当前元素乘上一轮最小值。

代码：maxCur = max({nums[i], tempMax*nums[i], tempMin*nums[i]}); minCur = min({nums[i], tempMax*nums[i], tempMin*nums[i]});
LeetCode 978. 最长湍流子数组比较符号交替思路：动态规划。up[i] 表示以 i 结尾且 arr[i] > arr[i-1] 的最长湍流长度；down[i] 表示以 i 结尾且 arr[i] < arr[i-1] 的最长湍流长度。状态转移：若 arr[i] > arr[i-1]，则 up[i] = down[i-1] + 1；若 arr[i] < arr[i-1]，则 down[i] = up[i-1] + 1。

代码：if (arr[i] > arr[i-1]) { up = down + 1; down = 1; } else if (arr[i] < arr[i-1]) { down = up + 1; up = 1; } else { up = down = 1; }
LeetCode 560. 和为K的子数组统计个数思路：前缀和 + 哈希表。遍历时维护当前前缀和 sum，查询哈希表中是否存在 sum - k，若存在则累加次数。哈希表记录每个前缀和出现的次数。

代码：if (prefixCount.count(sum - k)) count += prefixCount[sum - k]; prefixCount[sum]++;
LeetCode 209. 长度最小的子数组目标和≥s的最小长度思路：滑动窗口。右指针不断累加，当窗口和 ≥ target 时，不断收缩左指针并更新最小长度。

代码：while (sum >= target) { minLen = min(minLen, right - left + 1); sum -= nums[left++]; }
