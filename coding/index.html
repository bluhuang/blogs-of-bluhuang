    贪心算法是一种在每一步选择中都采取当前最优决策，从而希望得到全局最优解的算法思想。它并非对所有问题都有效，但在满足“贪心选择性质”和“最优子结构”的问题中，能够以极高的效率得到正确答案。 一、贪心算法的适用特征 贪心选择性质 局部最优选择可以导致全局最优解。即无需考虑子问题的解，直接做出当前看起来最好的选择，后续问题结构与原问题相同。 最优子结构 问题的最优解包含其子问题的最优解。这是动态规划和贪心共有的性质，但贪心要求子问题独立且选择不影响后续结构（或影响可控）。 常见问题类型 · 区间调度：选择最多不重叠区间、最少点覆盖所有区间等。 · 资源分配：最小化等待时间、最大化收益等。 · 图论：最小生成树（Prim、Kruskal）、最短路径（Dijkstra）。 · 序列问题：最长递增子序列（贪心+二分）、跳跃游戏、加油站等。 · 排序后贪心：通常先将数据按某种规则排序，再顺序决策。 二、贪心算法的解题套路 确定贪心策略 · 思考方向：每一步要选择什么？是选“最小/最大”、“最早结束/最晚开始”、“价值/重量比最高”？ · 常见策略： · 按结束时间排序 → 区间调度 · 按价值/重量比排序 → 部分背包 · 按起始时间排序 → 合并区间 · 维护一个“最优结构”，如最长递增子序列中的“尽可能小的末尾值” 证明贪心正确性（可通过交换论证或归纳法理解） · 交换论证：假设存在一个最优解，若其中一步不满足贪心选择，通过交换相邻元素可以得到不差于原解的解。 · 归纳法：证明每一步贪心后，剩余问题与原问题同构，且原问题的最优解可由贪心解扩展得到。 实现技巧 · 排序：大多数贪心题需要先排序。 · 数据结构优化： · 堆（优先队列）用于动态取最小/最大。 · 平衡树 / 二分查找 用于维护有序序列。 · 双指针 / 单调栈 等辅助。 三、典型案例：最长递增子序列（LIS）的贪心+二分 问题 给定一个未排序的整数数组，求最长严格递增子序列的长度。 贪心思路 · 维护一个数组 tails，其中 tails[i] 表示长度为 i+1 的递增子序列的最小末尾元素。 · 遍历原数组每个数 x： · 若 x 大于 tails 中所有数，则追加到末尾，长度增加。 · 否则，用二分查找找到第一个 tails[i] >= x 的位置，并用 x 替换它。 · 最终 tails 的长度即为 LIS 长度。 ...
