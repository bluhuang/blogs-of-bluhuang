学习笔记生成要求

我需要你围绕我指定的技术主题，生成一份自包含、可直接学习的笔记，兼顾理论和实践。请遵循以下规则：

1. 内容来源

  • 你需要主动从网络搜索高质量资料（优先选择：权威博客、技术社区、论文、官方文档）。
  • 至少引用 2-3 篇有代表性的文章或论文（在笔记末尾列出参考链接）。

2. 笔记结构（必须包含）

  • 核心概念精讲：用通俗语言解释关键术语/原理，确保读者能直接从笔记中理解，无需查其他资料。
  • 对比表格：当存在多种方案/模型/策略时，用表格列出优缺点、适用场景、关键差异。
  • 知识速查卡：以 Q&A 形式总结 3-5 个常见技术问题，给出简洁但完整的回答要点。

3. 格式与风格

  • 使用 Markdown，标题层级从 ## 开始。
  • 避免大段抽象论述，尽量结构化（列表、表格、小标题）。
  • 不用给出可运行的代码（除非我特别要求），但可以描述伪代码或逻辑。
  • 术语第一次出现时给出英文全称和缩写。
  • 如果涉及数学公式，用 LaTeX 格式（$...$ 或 $$...$$）。

4. 深度要求

  • 原理层面：讲清楚“为什么”和“怎么做”，不要只罗列概念。
  • 实战导向：能指导我理解该技术在我的 RAG 项目中的价值或集成方式。
  • 问题回答控制在 2-3 句话，命中核心要点。

5. 特别偏好

  • 拒绝空泛的“重要性”论述，直接进入实质内容。
  • 如果该技术有常见误区，请单独指出。
  • 如果涉及中文处理（如分词），需说明中文场景的特殊性和选型建议。
  • 笔记必须自包含，读者看完笔记就能掌握该技术的核心知识，不需要再去其他地方查找。

6. 输出格式

直接返回笔记正文，不要添加额外解释（如“好的，这是你的笔记”）。如果信息不足以生成完整笔记，请提问澄清。
