GPT连接Github - 授权不代表真连接

BluHuang / Z mixed / 2026年7月27日

最近我想让 ChatGPT 读取自己的 GitHub 私有仓库，结果在连接过程中踩了一个非常隐蔽的坑。

表面上看，已经在 ChatGPT 的 GitHub 应用中完成登录和授权，GitHub 的 Authorized OAuth Apps 页面里也能看到 ChatGPT。整个流程看起来都成功了。

但回到 ChatGPT 后，私有仓库始终不可见。

更让人困惑的是，首次授权过程中并没有出现“选择仓库”的页面；GitHub 的 Installed GitHub Apps 中也找不到 ChatGPT。反复断开、重新连接，结果仍然一样。

最后才发现：

GitHub 账号授权成功，只完成了 OAuth 登录；要读取私有仓库，还必须单独安装 ChatGPT Codex Connector GitHub App，并明确授予目标仓库的访问权限。

真正缺失的步骤

帮助文档中有这样一段说明：

私有或新创建的代码仓库：如果你的代码仓库是私有的，或是在最初连接到 GitHub 后创建的，它可能不会立即显示在 ChatGPT 中。请访问此链接，或在 ChatGPT 中 GitHub 的设置页面点按齿轮图标，以配置对所需代码仓库的访问权限。

帮助文档：

https://help.openai.com/zh-hans-cn/articles/11145903-connecting-github-to-chatgpt

真正关键的是文档中隐藏的这个链接：

https://github.com/apps/chatgpt-codex-connector/installations/select_target

打开后，才会进入 GitHub App 的正式安装流程：

  1. 选择 GitHub 个人账号或组织。

  2. 选择 Only select repositories。

  3. 勾选需要向 ChatGPT 开放的私有仓库。

  4. 点击 Install 或 Save。

  5. 等待 ChatGPT 同步仓库权限。

安装完成后，再进入：

GitHub → Settings → Applications → Installed GitHub Apps

此时才能看到：

ChatGPT Codex Connector

而不是只在：

Authorized OAuth Apps

里看到 ChatGPT。

OAuth 授权和 GitHub App 安装不是一回事

这是整个流程中最容易误解的地方。

OAuth 授权

OAuth 主要完成：

  • 登录 GitHub 账号；

  • 确认用户身份；

  • 允许 ChatGPT 获取基础账号信息。

它不一定意味着 ChatGPT 已获得某个私有仓库的访问权限。

GitHub App 安装

GitHub App 才负责：

  • 选择具体账号或组织；

  • 选择允许访问的代码仓库；

  • 控制私有仓库权限；

  • 让 ChatGPT 真正读取仓库文件、提交和历史记录。

所以，看到“授权成功”并不代表连接已经完整完成。

如何判断自己是否踩了同一个坑

如果你遇到以下现象，大概率就是只完成了 OAuth 授权：

  • ChatGPT 中显示 GitHub 已连接；

  • GitHub 的 Authorized OAuth Apps 中可以看到 ChatGPT；

  • Installed GitHub Apps 中没有 ChatGPT Codex Connector；

  • 授权时没有出现仓库选择页面；

  • 公开仓库可能能搜索，私有仓库始终不可见；

  • ChatGPT 显示可访问仓库数量为 0。

这时不要继续反复断开重连，直接打开 GitHub App 安装链接：

https://github.com/apps/chatgpt-codex-connector/installations/select_target

为什么这个流程很坑

问题并不在于流程复杂，而在于关键步骤藏得太深。

正常用户会自然认为：

点击连接 GitHub
→ 登录 GitHub
→ 点击授权
→ 连接完成

但实际流程是：

连接 GitHub
→ OAuth 登录授权
→ 找到帮助文档中的隐藏链接
→ 安装 ChatGPT Codex Connector
→ 选择目标仓库
→ 授予私有仓库权限
→ 等待同步

如果没有主动点开帮助文档中的超链接，用户几乎无法知道还缺少一个 GitHub App 安装步骤。

而且 GitHub 后台把两种状态分开放在：

Authorized OAuth Apps
Installed GitHub Apps

这进一步增加了理解成本。

最终正确操作流程

完整流程可以简化为：

ChatGPT 设置
→ 应用
→ GitHub
→ 登录并授权 GitHub
→ 打开 ChatGPT Codex Connector 安装链接
→ 选择账号
→ Only select repositories
→ 勾选私有仓库
→ Install
→ 返回 ChatGPT 等待同步

如果你已经完成授权，但始终看不到私有仓库，不要急着怀疑账号、仓库索引或同步速度。

先检查：

GitHub → Settings → Applications → Installed GitHub Apps

只要里面没有 ChatGPT Codex Connector，就说明连接流程还没有真正完成。

总结

ChatGPT 连接 GitHub 时：

OAuth 授权只代表账号登录成功，GitHub App 安装和仓库授权才代表私有仓库真正接入成功。

真正关键的安装入口是：

https://github.com/apps/chatgpt-codex-connector/installations/select_target

这个入口本应直接出现在连接流程中，而不是藏在帮助文档的一段文字里。希望这篇记录能帮其他人少浪费一点时间。
