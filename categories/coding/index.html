括号问题全解：LeetCode 32 栈解法 + 通用决策框架 一、LeetCode 32 最长有效括号 — 栈解法精要 1. 题目与题型 题目：给定只含 ( 和 ) 的字符串，找出最长有效（连续且合法）括号子串的长度。 题型：括号匹配 · 最长连续有效子串 2. 核心思路（栈存下标） 栈底始终保存 最后一个无效位置的索引（初始为 -1）。 遍历字符串，索引为 i： 遇 (：压入下标 i。 遇 )：先弹栈（无论栈顶是什么）。 弹栈后栈空 → 当前 ) 是新的无效断点，压入 i。 弹栈后栈非空 → 匹配成功，有效长度 = i - stk.top()，更新答案。 3. 复杂度 时间：O(n) 空间：O(n) 4. C++ 实现 int longestValidParentheses(string s) { stack<int> stk; stk.push(-1); int ans = 0; for (int i = 0; i < s.size(); ++i) { if (s[i] == '(') { stk.push(i); } else { stk.pop(); if (stk.empty()) stk.push(i); else ans = max(ans, i - stk.top()); } } return ans; } 关键细节 · 为什么存下标？ 因为需要计算长度（位置差），长度 = 当前下标 − 栈顶下标。 · 为什么栈底预存 -1？ 统一长度计算公式。当有效子串从开头即匹配时（如 “()"），弹栈后栈变空，有了 -1 仍可计算差值。
