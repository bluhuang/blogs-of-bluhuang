BLC 黑电平校正

什么是黑电平？为什么 Sensor 在全黑时读数不是 0？BLC 是如何把它矫正回来的？

1. 什么是 BLC

1.1 BLC 的定义

BLC（Black Level Correction，黑电平校正） 是 ISP 流程中的第一个处理步骤，目的是将 Sensor 在全黑环境下的非零输出值修正为 0。

术语解释：黑电平（Black Level） 是 Sensor 在完全无光（全黑）条件下输出的像素值。理想情况下它应该是 0，但实际 Sensor 由于硬件特性，全黑时输出的是一个固定的正数（如 256 或 300）。校正（Correction） 就是把这个固定偏置减去，使黑色的起点归零。

1.2 BLC 在 ISP 流程中的位置

Sensor 输出（Bayer RAW）
    ↓
【BLC 黑电平校正】  ← 第一步
    ↓
DPC 坏点校正
    ↓
BNR / AIBNR 去噪
    ↓
数字增益
    ↓
...后续 ISP 处理

为什么 BLC 必须是第一步？

  • 后续所有处理（DPC、BNR、数字增益、Demosaic 等）都假设输入数据从 0 开始
  • 如果不先做 BLC，黑电平偏置会被后续的数字增益放大，导致整张图偏亮（暗部发灰）
  • 坏点检测、噪声建模等算法都依赖正确的黑电平基准

2. 为什么会存在黑电平

2.1 物理原因：Sensor 读出电路的“底噪”

Sensor 把光信号转换成电信号，再经过 ADC（模数转换器）变成数字值。这个过程中存在一个固定偏置：

  • 暗电流（Dark Current）：即使没有光，Sensor 内部的热运动也会产生少量电子，这些电子被 ADC 读取后表现为一个固定的正偏置
  • 读出噪声（Read Noise）：ADC 转换时本身有一个基准偏移

术语解释：暗电流（Dark Current） 是 Sensor 在无光条件下因热运动产生的电荷积累。温度越高，暗电流越大。ADC（模数转换器） 是把 Sensor 的模拟电压信号转换成数字值的电路。两者的共同作用导致 Sensor 在全黑时输出一个非零的正数。

2.2 量化原因：ADC 的“绝对编码”方式

12-bit ADC 的输出范围是 0~4095。ADC 用这个范围来表示 Sensor 电压的最小值到最大值：

  • 如果 ADC 从 0 开始计数，Sensor 的底噪（读出噪声）会让输出在 0 附近波动，导致信息丢失
  • 所以 Sensor 厂商会把 ADC 的起始基准点抬高（比如让 ADC 从 64 或 256 开始计数），确保底噪被“容纳”在有效范围之外，从而保留全部图像信息

结果：全黑输出 = 一个固定的正数，这就是黑电平。

3. 黑电平是固定的吗？

不是完全固定。

3.1 全局黑电平

大多数 Sensor 的黑电平是一个全局常数，如 256 或 300。全局黑电平通常由 Sensor 厂商提供。

3.2 位置相关的黑电平（FPN）

由于芯片制造工艺不均匀，Sensor 不同位置的暗电流可能不同，导致全黑时不同像素的输出略有差异。

术语解释：FPN（Fixed Pattern Noise，固定模式噪声） 是 Sensor 上位置固定的像素偏差——某些像素在全黑时比其他像素更亮或更暗。这不是随机噪声，而是位置固定、模式固定的偏差，可以通过黑电平地图（FPN 图）来扣除。

处理方式：

  • 在全黑环境下拍摄一张参考图（FPN 图），记录每个像素的黑电平值
  • 在 BLC 时，对每个像素减去对应的 FPN 值（而不是一个全局常数）

3.3 黑电平在代码中的体现

黑电平类型代码中的形式说明
全局黑电平一个整数（如 64、256、300）所有像素减去同一个值
FPN 图一张 2D 数组（H×W）每个像素有各自的黑电平值

4. BLC 的计算

4.1 全局黑电平校正

最简单的 BLC：对每个像素减去同一个黑电平常数。

raw_blc = raw - black_level

其中 black_level 是一个固定的常数（如 256）。

4.2 带数字增益的 BLC

在实际 ISP 中，BLC 通常与数字增益（DGain）配合：

raw_blc = (raw - black_level) × dgain + net_bl
符号含义
rawSensor 原始输出
black_level传感器黑电平（Sensor 全黑时的固定偏置）
dgain数字增益（ISP 自动曝光控制）
net_bl归一化黑电平（把数值范围重新映射到标准区间）

为什么先减后乘？ 先扣除黑电平把基准归零，再乘增益放大信号。如果先乘后减，黑电平偏置也会被放大，导致暗部发灰。

4.3 用具体数字走一遍

假设一个 Sensor 的黑电平 black_level = 256，net_bl = 300，dgain = 1.5。两个像素的原始值分别是：

像素rawraw - 256乘 dgain加 net_bl最终输出
暗部（全黑）25600300300
正常像素100074411163001416

说明：

  • 全黑像素输出从 256 变成了 300（中间值），而不是 0，因为 net_bl 不是 0
  • 在推理脚本中，net_bl 通常设为 300，表示黑电平被归一化到一个标准区间（0~4095 的中间偏暗位置）
  • 不同框架对 net_bl 的定义不同——有的把它作为黑电平基准值，有的把它作为归零目标值

4.4 FPN 校正

FPN 校正用黑电平地图（FPN 图）来校正每个像素：

raw_blc = raw - fpn_map[x, y]

其中 fpn_map[x, y] 是位置 (x, y) 的黑电平值。

5. 代码中的 BLC

5.1 推理脚本中的 BLC

在一种常见做法的推理脚本中：

# 黑电平扣除 + ISP DGain + 归一化黑电平
raw_seq_decomposed = np.clip(
    np.around((raw_seq_decomposed.astype(np.float32) - sensor_bl) 
              * ispdgain_ratio.reshape(...)) + net_bl,
    0.0, 4095.0
)

参数说明：

  • sensor_bl：传感器黑电平（由 sensor_profile.py 提供，如 64）
  • ispdgain_ratio：ISP 数字增益（如 1024/1024 = 1.0）
  • net_bl：归一化黑电平（通常为 300）

5.2 训练代码中的 BLC

在一种常见做法的训练代码中，黑电平可能不显式出现在训练脚本里，而是内嵌在数据加载或预处理中：

# 在数据加载的 HDF5 中，黑电平可能已经被扣除
# 或者在线生成噪声时 implicit 处理
net_bl = 300  # 训练配置中的归一化黑电平

6. 一句话总结

BLC（黑电平校正） 把 Sensor 在全黑时的非零输出（如 64、256、300）减去或归一化，使黑色的起点归零。它必须放在 ISP 流程的第一步，因为后续所有处理都依赖正确的黑电平基准。黑电平的来源是 Sensor 读出电路的暗电流和 ADC 基准偏移。在代码中，BLC 通常表现为 raw = (raw - black_level) × dgain + net_bl 的形式。
