BNR（拜耳域降噪）

BNR（Bayer Noise Reduction）是 RAW 域处理 的一个环节，位于 BLC 和 DPC 之后、数字增益之前。现在要回答的问题是：为什么要在 Bayer 域做降噪？怎么做？传统 BNR 和 AIBNR 有什么区别？

1. 什么是 BNR

1.1 BNR 的定义

BNR（Bayer Noise Reduction，拜耳域降噪） 是在 ISP 流程的 RAW 域 对 Bayer 马赛克数据进行的降噪操作。

术语解释：拜耳域（Bayer Domain） 指的是数据仍处于 Bayer 马赛克格式的阶段——每个像素只记录了 R、G、B 三种颜色中的一种，尚未经过 Demosaic（去马赛克）还原成 RGB 全彩图。

BNR 是 ISP 流程中 第一个降噪环节，也是 最重要 的一个。它在 RAW 域直接处理 Sensor 的原始数据，后续所有 ISP 模块（Demosaic、AWB、CCM、Gamma 等）都会基于 BNR 的输出继续处理。

1.2 BNR 在 ISP 流程中的位置

Bayer RAW → BLC → DPC → 【BNR】 → 数字增益 → Demosaic → AWB → CCM → Gamma → ...

为什么插在这个位置？

  • 在 BLC 和 DPC 之后：先保证数据正确（黑电平归零、坏点修复）
  • 在数字增益之前：先降噪，后放大，避免放大噪声
  • 在 Demosaic 之前：在 Bayer 域去噪，噪声还未被插值扩散

1.3 BNR 的输入输出

输入输出
数据格式Bayer 马赛克（1 通道）Bayer 马赛克（1 通道）
通道数11
空间尺寸H × WH × W
数据范围12-bit / 14-bit 线性12-bit / 14-bit 线性

关键点：BNR 不改变数据格式——输入是 Bayer 马赛克，输出还是 Bayer 马赛克。它只修改像素值（去掉噪声），不改变排列方式。

2. 为什么在 Bayer 域做降噪

2.1 噪声在不同域的表现

处理阶段噪声特点降噪难度
RAW 域（Bayer）噪声独立分布于每个像素，未经过任何插值，是“原始形态”最容易
RGB 域经过 Demosaic 插值后，噪声被扩散到周围像素，变得“模糊”中等
YUV 域经过多次非线性变换，噪声分布复杂最难

术语解释：插值（Interpolation） 是 Demosaic 的核心操作——Bayer 马赛克中每个像素只有一种颜色，Demosaic 用周围像素的值来“猜”出缺失的两种颜色。这个“猜”的过程会把噪声也扩散到相邻像素，让噪声从“孤立点”变成“模糊斑块”，更难去除。

2.2 在 RAW 域降噪的优势

优势说明
噪声未扩散噪声还是“孤立像素点”，模式简单，容易检测
信息最完整保留 Sensor 的全部动态范围（12-bit/14-bit），没有被压缩或非线性变换
更准确的噪声建模RAW 域的噪声符合泊松-高斯模型（k/b 参数就是在这个域定义的）
效率更高在后续处理之前就把噪声去掉，避免噪声被放大或扩散

2.3 如果不做 BNR，会发生什么？

带噪 Bayer → Demosaic → 噪声被插值扩散 → 变成模糊的彩色噪点 → 后续处理更难去除

如果 BNR 做得不好，后续的 AWB、CCM 等操作会把噪声进一步放大，最终图像会出现明显的彩色噪声颗粒。

3. 传统 BNR 算法

3.1 核心思想

传统 BNR 用 滤波算法 在 Bayer 域做降噪。滤波的核心逻辑是：

输出像素 = 当前像素 × 权重 + 周围像素 × 权重

不同的是“权重”怎么算。传统 BNR 的权重由像素值差异和空间距离决定，不涉及学习过程——参数是固定的，不会随数据变化。

3.2 常见算法

双边滤波（Bilateral Filter）

核心公式：

输出 = (1/W) × Σ( 像素值 × 空间权重 × 值域权重 )
  • 空间权重：距离中心越近，权重越大（高斯分布）
  • 值域权重：像素值与中心越接近，权重越大（高斯分布）

关键区别：传统的高斯滤波只看距离（近的就加权平均），所以它会把边缘也一起模糊掉。双边滤波多了一个“值域权重”，颜色/亮度跟我越像的像素，说话分量越重；跟我不像的（可能是边缘），分量轻。

Bayer 域双边滤波的特殊处理：

  • 只滤波同色像素（如只对 R 像素周围的其他 R 像素做加权平均），因为不同颜色的像素值差异不一定是噪声，可能是颜色本身。
  • 窗口大小通常是 5×5 或 7×7，只取同色像素参与计算。

引导滤波（Guided Filter）

引导滤波的核心思路是：“我不靠自己的像素值来做决定，而是找一张更可靠的图来指挥我。”

具体是怎么做的？

你有一张带噪的输入图（比如模糊的、有颗粒感的图）。你同时还准备了一张**“引导图”（Guided Image）。这张引导图通常是输入图的平滑版**（比如去掉噪声后的模糊图），或者是有清晰边缘的其他图像。

  • 引导滤波会分析这张引导图：哪里有边缘？哪里是平坦区域？
  • 然后它建立一个简单的线性模型：输出像素 = a × 输入像素 + b。其中 a 和 b 是由引导图决定的。
  • 如果引导图说这里是平坦区域：a 接近 0，b 接近平均值，相当于做平滑（去噪）。
  • 如果引导图说这里是边缘：a 接近 1，b 接近 0，相当于直接保留原值（保边）。

关键区别：双边滤波是在“原地”靠自己的像素值判断自己是不是边缘（有点“自说自话”）。而引导滤波是看“别人”（引导图）的脸色行事。因为引导图是更干净、更平滑的版本，它的判断往往更准确，而且计算更快。

非局部均值（Non-Local Means）

非局部均值（Non-Local Means）的思路和前面两种完全不同。前面两种是看周围邻居（局部），NLM 是看整个世界（非局部）。

核心思路：图像里有很多重复的纹理（比如砖墙、草地、毛衣纹理）。与其只靠周围几个像素平均，不如在整张图里**找相似的块（Patch）**来平均。

具体是怎么做的？

  1. 在每个像素周围取一个小块（比如 7×7）。
  2. 然后在整个图像里搜索看起来相似的小块（用像素差异来判断相似度）。
  3. 把所有这些相似块加权平均，替代当前像素值。

效果：噪声在大量相似块的加权平均中被抵消，真实的纹理因为块间相似性高而被保留。这种方法对重复纹理多的图像（如草地、天空）效果很好，但缺点是计算量极大（要在全图搜索相似块），不适合实时处理。

3.3 传统 BNR 的局限

局限说明
参数固定滤波强度由人工设定，无法根据图像内容自适应调整，容易出现“去不干净”或“把细节抹掉”的情况
无法区分噪声和纹理高频纹理容易被当作噪声滤掉
运动场景受限多帧降噪需要精确的运动估计，传统算法在复杂运动场景中效果差

4. AIBNR（AI 拜耳域降噪）

4.1 核心思想

AIBNR（AI Bayer Noise Reduction） 用深度学习神经网络（如 SNR 模型）替代传统滤波算法，从大量带噪/干净配对数据中学习“如何区分噪声和真实纹理”，而不是依赖人工设定的滤波参数。

关键区别：

  • 传统 BNR：用固定公式计算权重
  • AIBNR：用神经网络从数据中学习权重

4.2 AIBNR 的输入输出

AIBNR 的输入不仅仅是“带噪的 Bayer RAW 图”，还包括噪声参数，让模型根据噪声强度动态调整去噪力度：

AIBNR 输入：
├── 带噪 Bayer RAW（1 通道，H×W）
├── k_map（噪声强度参数，H×W）
├── b_map（噪声底噪参数，H×W）
└── noise_ctr（去噪强度控制旋钮，标量）

AIBNR 输出：
└── 去噪后的 Bayer RAW（1 通道，H×W）

术语解释：k_map / b_map 是噪声模型的参数图。k 描述噪声随亮度变化的斜率（信号相关噪声），b 描述不随亮度变化的底噪（信号无关噪声）。它们是空间图（每个像素位置都有一个值），因为镜头暗角导致图像边缘比中心暗，噪声强度也随位置变化。

4.3 AIBNR 的优势

优势说明
自适应去噪根据 k/b 参数自动调整去噪力度，暗部强去噪、亮部轻去噪
纹理保留更好学习大量数据后，能区分“噪声”和“真实纹理”
泛化能力通过训练数据覆盖多种场景，比手工调参的传统算法鲁棒性更强

4.4 AIBNR 的局限

局限说明
需要训练数据依赖大量带噪/干净配对数据，数据获取成本高
算力需求神经网络推理需要 NPU 算力，传统 BNR 在硬件上更便宜
模型迁移换 Sensor 需要重新训练或微调

5. 传统 BNR vs AIBNR 对比

对比维度传统 BNRAIBNR
核心方法滤波算法（双边滤波/引导滤波等）深度神经网络
参数来源人工设定固定参数从数据中学习
纹理保留依赖参数调节，高频纹理容易丢失好（通过学习区分噪声和纹理）
自适应能力弱（固定参数）强（通过 k/b 参数调整力度）
计算成本低（硬件友好）高（需要 NPU）
泛化能力差（换场景需重新调参）好（覆盖多种训练场景）
训练数据需求无需要大量配对数据

7. 一句话总结

BNR 是在 Bayer 域做的第一次降噪，位于 BLC/DPC 之后、Demosaic 之前。传统 BNR 用固定参数的滤波算法，AIBNR 用神经网络自适应去噪。您的 SNR 模型就是 AIBNR 的一种实现——输入带噪 Bayer RAW + k/b 参数，输出去噪后的 Bayer RAW。在 RAW 域降噪的优势是噪声还未被 Demosaic 插值扩散，保留最多原始信息。
