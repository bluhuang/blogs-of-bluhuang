ISP 图像信号处理器（Image Signal Processor）

BluHuang / Ai / 2026年7月1日

ISP 图像信号处理器

RAW 图经过去噪后，还要经过哪些步骤才能变成人眼看到的彩色图像？

1. 什么是 ISP

ISP 的全称是 Image Signal Processor（图像信号处理器）。它是 Sensor 输出 RAW 图之后，到最终输出彩色图像（YUV 或 RGB）之间的完整处理链路。

Sensor 输出的是 Bayer RAW 数据，它不能直接显示。ISP 的任务就是把 RAW 数据经过一系列处理，变成人眼能看的彩色图。

Sensor → RAW 图（不能看）→ ISP 处理 → 彩色图（能看）

ISP 通常包含几十个处理步骤。在手机、安防摄像头等设备上，ISP 由硬件电路（专门的芯片模块）执行。在 PC 端训练模型时，ISP 中的某些部分（如 RAW2YUV）被模拟成可微分的 Python 代码，用于在训练中提供颜色空间的梯度信号。

ISP 的处理步骤有固定的顺序，因为每一步的输入依赖前一步的输出。

2. ISP 的输入和输出

输入输出
格式Bayer RAW（马赛克排列）YUV 或 RGB（全彩色）
通道数1 通道（每个像素只有一种颜色）3 通道（每个像素有 Y/U/V 或 R/G/B）
动态范围12-bit / 14-bit 线性8-bit / 10-bit 非线性
视觉外观灰绿色马赛克（不可看）正常彩色图像（可看）

ISP 的输入是 Sensor 直接输出的 RAW 数据，输出是显示设备能识别的彩色图像。

3. ISP 的三阶段结构

ISP 的处理顺序分为三个阶段。划分依据是数据格式：

┌─────────────────────────────────────────────────────────────────────────────┐
│                    ISP 流程的三阶段划分                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  阶段一：RAW 域                                                            │
│  数据格式：Bayer 马赛克（1 通道）                                          │
│  核心操作：BLC → DPC → BNR/AIBNR → 数字增益                              │
│  目的：从 Sensor 原始数据中去除物理缺陷和噪声                              │
│                                                                             │
│  阶段二：RGB 域                                                            │
│  数据格式：RGB（3 通道）                                                   │
│  核心操作：Demosaic → AWB → CCM → Gamma                                  │
│  目的：把马赛克还原成彩色图，校正颜色到标准空间                            │
│                                                                             │
│  阶段三：YUV 域                                                            │
│  数据格式：YUV（3 通道）                                                   │
│  核心操作：RGB→YUV → 3DNR → 锐化 → 色彩增强                             │
│  目的：针对人眼感知做最终优化                                              │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

每个阶段处理一种特定的数据格式，阶段之间有明确的输入输出依赖，顺序不可交换。

RAW 域：ISP 处理的第一阶段，数据格式为 Bayer 马赛克（1 通道），每个像素只记录 R/G/B 中的一种颜色，尚未经过任何颜色插值或校正。

Bayer 马赛克：Sensor 表面覆盖的 RGGB 颜色滤镜阵列，每个像素只能记录一种颜色，必须经过 Demosaic 才能变成全彩色图像。

BLC（黑电平校正）：减去 Sensor 在全黑环境下的固定偏置（如 256），让黑色起点归零，防止暗部发灰。

DPC（坏点校正）：检测并替换 Sensor 上永远偏亮或永远偏暗的故障像素，用周围正常像素的值填补。

BNR（Bayer 域降噪）：在 RAW 域对 Bayer 马赛克数据做降噪，利用 RAW 图的全动态范围优势，比在 RGB 域降噪效果更好。

AIBNR：用深度学习神经网络（如 SNR 模型）替代传统 BNR 滤波算法，输入 Bayer RAW + k/b 噪声参数，输出去噪后的 Bayer RAW。

数字增益（Digital Gain）：ISP 自动曝光控制的一部分，在去噪之后将信号整体放大，避免先放大再降噪时把噪声也放大。

Demosaic（去马赛克）：通过插值算法将 Bayer 马赛克（每像素 1 种颜色）还原成 RGB 全彩图（每像素 3 种颜色），是 Bayer→RGB 的关键步骤。

AWB（自动白平衡）：调整 R/G/B 通道的增益（如 r_gain=1.67, b_gain=1.57），让白色在不同光源下都显示为白色，消除色温导致的偏色。

CCM（色彩校正矩阵）：用一个 3×3 矩阵对 RGB 三通道做线性变换，将 Sensor 的颜色响应校正到标准色彩空间（如 sRGB），修正 Sensor 的色偏。

Gamma 校正：用幂函数 out = in^(1/2.2) 将物理线性亮度映射到人眼感知均匀的亮度空间，提升暗部细节可见度，是显示前的最后一步。

3DNR（三维降噪）：结合时域（多帧）和空域（单帧内）的降噪技术，利用相邻帧的噪声随机性，在 YUV 域做最终降噪。

锐化（Sharpen）：增强 Y 通道的高频分量（边缘细节），让图像看起来更清晰，通常只对 Y 通道做，因为人眼对亮度边缘最敏感。

色彩增强（Color Enhancement）：调整饱和度、对比度、色调等参数，让最终输出的图像色彩更鲜艳、更符合人眼审美。

4. 阶段一：RAW 域处理

RAW 域是 ISP 的第一个阶段，处理的是 Sensor 直接输出的 Bayer 数据。这个阶段的核心目的是清除 Sensor 物理层面的缺陷和噪声，为后续的颜色处理提供干净的数据。

RAW 域的数据格式是 Bayer 马赛克（1 通道），每个像素只记录 R、G、B 中的一种颜色。这个阶段的所有操作都不改变数据格式——输入是 Bayer RAW，输出还是 Bayer RAW。

4.1 BLC（黑电平校正，Black Level Correction）

什么是黑电平？

Sensor 在完全黑暗的环境下，像素读数不是 0，而是一个固定的正数。这个固定值就是黑电平（Black Level）。它取决于 Sensor 的硬件设计，通常在 256 左右（12-bit 数据）。

为什么要做 BLC？

因为 Sensor 的读出电路本身有底噪。如果读数从 256 开始，后续做数字增益（放大信号）时，底噪会被一起放大，导致暗部发灰。BLC 的作用就是把黑电平减去，让“黑色”的起点是 0。

BLC 的计算

raw_blc = raw - black_level

其中 black_level 是一个固定的常数（如 256）。

代码中的位置

在一种常见做法的推理脚本中：

raw_tmp = (raw - 256.0) * dgain + black_level

在另一种常见做法中，BLC 在训练数据预处理阶段完成，数据加载时已经减去了黑电平。

4.2 DPC（坏点校正，Defect Pixel Correction）

什么是坏点？

Sensor 制造过程中，个别像素可能异常——永远偏亮（亮坏点）或永远偏暗（暗坏点）。这些坏点的位置固定，如果不处理，最终图像会出现固定的亮点或暗点，人眼很容易察觉。

如何校正？

用周围正常像素的值来替换坏点。

坏点替换：
  检查当前像素与周围 3×3 窗口内像素的差异
  如果差异超过阈值 → 用窗口内中值替换当前像素

4.3 BNR（Bayer 域降噪）与 AIBNR

RAW 域降噪是 ISP 中最关键的处理步骤之一。Sensor 在低光环境下会产生大量噪声，如果不降噪，后续 Demosaic 等操作会把噪声放大，最终图像会布满噪点。

传统 BNR 的做法：用滤波算法（如双边滤波、引导滤波）在 Bayer 域做降噪。优点是速度快（硬件实现简单），缺点是参数固定，场景变化时效果不稳定。

AIBNR 的做法：用神经网络替代传统滤波算法。输入 Bayer RAW + 噪声参数（k/b），输出去噪后的 Bayer RAW。

传统 BNR：
Bayer RAW → 双边滤波 → 去噪后的 Bayer RAW

AIBNR：
Bayer RAW + k/b → 神经网络 → 去噪后的 Bayer RAW

AIBNR 为什么插在这个位置？

因为 RAW 域的数据还没有经过 Demosaic（去马赛克），噪声还没有被插值放大。在 RAW 域去噪，能保留最多的高频细节，效果最好。这也是为什么 RAW 图的去噪效果通常比 RGB 图去噪更好的原因——RGB 域的噪声已经经过插值扩散，更难分离。

4.4 数字增益（Digital Gain）

数字增益就是把信号整体放大。它通常由 ISP 的自动曝光（AE）算法控制。增益过大会放大噪声，所以通常放在 BNR 之后——先降噪，再放大，避免放大噪声。

5. 阶段二：RGB 域处理

RGB 域是 ISP 的第二个阶段。在进入 RGB 域之前，数据必须经过 Demosaic（去马赛克），把 Bayer 马赛克还原成 RGB 三通道彩色图。

RAW 域和 RGB 域的分界点是 Demosaic——Demosaic 之前是 RAW 域，之后是 RGB 域。

5.1 Demosaic（去马赛克）

Bayer 阵列中每个像素只有一种颜色。Demosaic 通过插值，让每个像素都拥有 R/G/B 三种颜色。

Bayer 马赛克输入（每个像素 1 种颜色）：
R  G  R  G
G  B  G  B
R  G  R  G
G  B  G  B

↓ Demosaic（插值）

RGB 输出（每个像素 3 种颜色）：
(R,G,B) (R,G,B) (R,G,B) (R,G,B)
(R,G,B) (R,G,B) (R,G,B) (R,G,B)
(R,G,B) (R,G,B) (R,G,B) (R,G,B)
(R,G,B) (R,G,B) (R,G,B) (R,G,B)

5.2 AWB（自动白平衡，Auto White Balance）

问题：不同光源下，同一张白纸看起来颜色不同。

光源白色外观原因
日光正常白色色温约 5500K
白炽灯偏黄色温约 2800K
阴天偏蓝色温约 6500K

AWB 的做法：调整 R、G、B 三通道的增益，让白色在任何光源下都显示为白色。

R_out = R_in × r_gain
G_out = G_in × g_gain（通常固定为 1.0）
B_out = B_in × b_gain

数字示例：

一个灰色像素的 Sensor 读数是 (R=100, G=120, B=80)。如果 r_gain=1.67, b_gain=1.57：

R_out = 100 × 1.67 = 167
G_out = 120 × 1.0 = 120
B_out = 80 × 1.57 = 126

三个通道的值被拉平，灰色被校正为中性色。

5.3 CCM（色彩校正矩阵，Color Correction Matrix）

问题：Sensor 对光谱的响应不完美，红色可能偏橙，蓝色可能偏紫。用 3×3 矩阵把颜色“映射”到标准色彩空间（如 sRGB）。

┌───┐   ┌             ┐   ┌───┐
│ R'│   │ m00 m01 m02 │   │ R │
│ G'│ = │ m10 m11 m12 │ × │ G │
│ B'│   │ m20 m21 m22 │   │ B │
└───┘   └             ┘   └───┘

AWB vs CCM：

AWBCCM
操作对角增益（3 个参数）3×3 矩阵（9 个参数）
作用只做独立通道增益跨通道混合校正
解决的问题色温偏色Sensor 光谱响应偏差

5.4 Gamma 校正

Gamma 校正你已经整理过笔记。它在 CCM 之后做，因为色彩校正必须在物理线性空间完成，Gamma 是最后的非线性映射。

Gamma 编码：out = in ^ (1/2.2)

人眼对暗部变化比亮部更敏感，Gamma 校正把有限的数值空间重新分配给暗部，让图像看起来更自然。

6. 阶段三：YUV 域处理

YUV 域是 ISP 的第三个阶段。数据从 RGB 转到 YUV 色彩空间后，亮度和色度被分离，可以分别优化。

6.1 RGB→YUV 转换

YUV 的三个通道：

通道全称含义
YLuma亮度（人眼最敏感）
UChrominance色度（蓝色-黄色轴）
VChrominance色度（红色-青色轴）

转换矩阵由标准定义（如 BT.601、BT.709）。

6.2 YUV 域的操作

在 YUV 域，Y 通道和 UV 通道可以独立处理：

  • Y 通道：做锐化（人眼对亮度边缘敏感）、做亮度降噪
  • UV 通道：做色彩增强、做色度降噪（人眼对色度不敏感，可以强降噪）

这也是训练中使用 YUV Loss 的原因——在训练时模拟 ISP 的 YUV 域处理，让模型在颜色空间上也能得到优化。

7. AIBNR 在整个 ISP 中的位置

┌─────────────────────────────────────────────────────────────────────────────┐
│                    ISP 流程（标注 AIBNR 位置）                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Sensor RAW（Bayer）                                                       │
│      ↓                                                                     │
│  BLC 黑电平校正                                                            │
│      ↓                                                                     │
│  DPC 坏点校正                                                              │
│      ↓                                                                     │
│  【AIBNR】← SNR 在这里                                           │
│      ↓                                                                     │
│  数字增益                                                                  │
│      ↓                                                                     │
│  Demosaic（Bayer → RGB）                                                  │
│      ↓                                                                     │
│  AWB                                                                       │
│      ↓                                                                     │
│  CCM                                                                       │
│      ↓                                                                     │
│  Gamma                                                                     │
│      ↓                                                                     │
│  RGB→YUV                                                                   │
│      ↓                                                                     │
│  YUV 域处理（3DNR、锐化、色彩增强）                                        │
│      ↓                                                                     │
│  最终输出（YUV/RGB）                                                      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

AIBNR 插在 RAW 域的 BNR 位置。它的输入是带噪声的 Bayer RAW，输出是去噪后的 Bayer RAW。格式不变，位置不变，只替换了“降噪”这个操作本身。

9. 一句话总结

ISP 是 Sensor RAW 到彩色图像之间的完整处理链路，分为 RAW 域（去噪、校正）、RGB 域（去马赛克、色彩校正）和 YUV 域（锐化、色彩增强）三个阶段。你的 AIBNR 模型插在 RAW 域的 BNR 位置。理解 ISP 流程，你才能理解自己的模型在整个成像系统中处于什么位置。
