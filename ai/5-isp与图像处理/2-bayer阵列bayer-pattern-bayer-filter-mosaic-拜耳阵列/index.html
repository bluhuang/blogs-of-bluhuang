Bayer阵列（Bayer Pattern, Bayer Filter Mosaic, 拜耳阵列）

Bayer阵列（Bayer Pattern / Bayer Filter Mosaic） 是数码相机、手机摄像头等几乎所有消费级图像传感器的底层核心技术。

简单来说，它是一个"颜色滤镜马赛克"，解决了"单个像素只能感知光的强弱（灰度），无法感知颜色“这个物理限制。

1. 一个根本问题：传感器是“色盲”

我们使用的数码相机、手机摄像头，其中的核心部件是 图像传感器（Image Sensor），其基本单元是无数个光电二极管（Photodiode）。

光电二极管只做一件事：感知光的强度（明暗），它完全无法分辨光的颜色（波长）。

因此，从传感器直接读出的原始数据（RAW图）其实是一张黑白照片，记录的是每个像素位置的亮度信息。

核心矛盾：我们希望得到彩色照片，但传感器天生是“色盲”。怎么办？

2. 解决方案：在传感器上盖一层“彩色玻璃”

拜耳阵列（Bayer Array） 就是用来解决这个矛盾的方案。 它的做法非常巧妙：在每个像素点上面覆盖一块微小的彩色滤光片（Color Filter），只允许特定颜色的光通过。 例如：

  • 覆盖红色滤光片的像素：只记录红色的亮度。
  • 覆盖绿色滤光片的像素：只记录绿色的亮度。
  • 覆盖蓝色滤光片的像素：只记录蓝色的亮度。

这些红、绿、蓝滤光片并非随意排列，而是遵循一种特定的棋盘格式马赛克图案。这个图案，就是 拜耳阵列（Bayer Pattern） 。

3. 拜耳阵列长什么样？

最经典的拜耳阵列是 RGGB 排列。 在一个 2×2 的像素网格里，排列如下：

 R  G
 G  B
  • R (Red)：红色滤光片
  • G (Green)：绿色滤光片
  • B (Blue)：蓝色滤光片

整个传感器由无数个这样的 2×2 RGGB 小单元拼接而成。

为什么绿色（G）有2个，而红（R）和蓝（B）各只有1个？

因为人眼对绿色最敏感。使用更多的绿色像素进行采样，可以更好地模拟人眼的视觉特性，使最终图像看起来更清晰、细节更丰富。因此，在拜耳阵列中，绿色像素占总数的 50%，红色和蓝色各占 25%。

除了 RGGB，还有 GRBG、BGGR 等变体，本质都是2绿、1红、1蓝的排列组合，只是起始位置不同。

4. 关键一步：从“马赛克”到“全彩图”

经过拜耳阵列后，传感器输出的图像是每个像素只有一种颜色的“马赛克图”。要将其变成我们熟悉的每个像素都有RGB三个值的全彩图，就需要一个关键步骤——去马赛克（Demosaicing）。

去马赛克：也称为 “解拜耳（Debayer）” 或 “色彩重建” 。简单来说，就是 “猜”。

它是如何“猜”的？ 以 RGGB 阵列中的一个 红色像素 为例，它只知道自己的红色值，却不知道绿色和蓝色值。去马赛克算法会参考它周围相邻像素的值，通过插值来估算缺失的绿色和蓝色值。

常见的插值算法：

  • 最近邻插值：直接复制最近的同色像素值。速度最快，但效果粗糙。
  • 双线性插值：取周围几个同色像素的平均值。效果平滑，但容易导致边缘模糊。
  • 更复杂的算法：会考虑边缘方向、纹理等因素，采用更精细的估算方式，效果更佳。

一个值得注意的事实：经过拜耳阵列和去马赛克处理后，一张全彩图中，仅有1/3的颜色信息是传感器真实测得的，另外2/3都是算法“猜”出来的。

5. 在代码中是如何体现的？

回顾代码：

sample = {
    'input':  [B, 4, H, W],   # 带噪声的Bayer RAW图
    ...
}

这里的 C=4 对应拜耳阵列的 4个通道（RGGB）。代码中的 _kron_canvas 函数，正是将原始的1通道马赛克数据拆解并堆叠成4个通道，以便神经网络处理。

数据流全景：

物理世界（彩色光） 
    ↓
传感器 + 拜耳阵列（每个像素只记录一种颜色） 
    ↓
RAW图（[B, 1, H, W]，马赛克状的黑白亮度数据）
    ↓
_kron_canvas() 拆解（RGGB → 4个通道）
    ↓
模型输入（[B, 4, H, W]）
    ↓
去噪 + 后续ISP处理（包括去马赛克、白平衡、Gamma校正等）
    ↓
最终彩色图像

6. 总结：拜耳阵列到底是什么？

拜耳阵列是数码相机能够用单块传感器拍出彩色照片的关键技术。其核心思想包括：

  1. 采样：使用红、绿、蓝滤光片覆盖像素，让每个像素只记录一种颜色。
  2. 猜色：后续通过“去马赛克”算法，根据相邻像素“猜”出缺失的颜色，最终合成全彩图。

它采用硬件上最简单的方案（一块传感器 + 一层滤光片），配合软件上精巧的算法（去马赛克），解决了“传感器是色盲”的根本问题。自1976年柯达工程师 Bryce Bayer 发明至今，它依然是绝大多数数码相机和手机摄像头采用的方案。

至于一般项目中选择在 Bayer RAW 域 进行去噪而非 RGB 域，正是为了在“猜色”之前保留最原始、最完整的信号信息，从而达到更好的去噪效果。
