1. 宏观概览：深度学习如何“学习”？

1.1 核心思想：神经网络是“万能函数近似器”

一句话定义：
一个训练好的神经网络，本质上是一个极其复杂的数学函数 y=f(x)y = f(x)y=f(x)。它能够把输入 xxx（比如一张噪声图片）映射到输出 yyy（比如一张干净图片）。
“万能近似定理”（Universal Approximation Theorem）说：只要网络有足够多的神经元和非线性激活函数，它就可以在理论上逼近任意函数——哪怕那个函数关系现实中根本写不出公式。

通俗理解：
你不需要知道“去噪”的物理公式是什么。你只需要给网络海量的 (噪声图, 干净图) 例子，它自己就能学会那个映射关系。就像你不需要懂语法也能学会说话——听多了就会。

关键点：

  • 参数（Parameters）：网络里的那些可调的“旋钮”，比如卷积核里的数值。学习就是不断拧这些旋钮，让输出越来越接近正确答案。
  • 拟合（Fitting）：网络在训练集上表现好的过程。但真正的挑战是泛化——在没见过的图上也要效果好。

1.2 核心学习循环：数据 → 模型 → 损失 → 反向传播 → 优化

这个循环是深度学习的“心脏”，每训练一个batch（一小批数据）就跳一次。下面拆解每一步：

┌─────────┐    ┌─────────┐    ┌─────────┐    ┌──────────┐    ┌────────┐
│  数据   │───→│  模型   │───→│  损失    │───→│ 反向传播 │───→│ 优化器 │
│ (Data)  │    │(Model)  │    │ (Loss)  │    │   (BP)   │    │(Optim) │
└─────────┘    └─────────┘    └─────────┘    └──────────┘    └───┬────┘
    ^                                                            │
    └───-───-───-───-───-───-───-───-───-───-───-───-────────────┘
                        更新模型参数 ──→ 回到“数据”

① 数据（Data）

  • 输入 xxx 和 目标 ytruey_{true}ytrue​。
  • 在AIBNR任务中：xxx 是带噪声的Bayer RAW图，ytruey_{true}ytrue​ 是对应的干净RAW图（通常通过多帧平均或长曝光获得）。
  • 数据通常分批（batch）送入，比如一次16张图。

ytruey_{true}ytrue​​ 是一个符号，代表 “真实目标值” 或 “标准答案”。 对于你负责的 AIBNR（AI拜耳域降噪） 任务来说：

  • 输入 xx：一张带有噪声的 Bayer RAW 图片（传感器直接输出的原始数据）。
  • 目标 ytruey_{true}ytrue​​ ​：与 xx 内容完全相同（同一场景、同一构图）、但 几乎没有噪声 的 干净 RAW 图片。

在实际项目中，y_{true}​ 是怎么得到的？ 真实环境下你不可能同时拍到“完全一样的场景，一个有噪声一个没有噪声”。所以工程上通常用两种方法制造 y_{true}​： 1. 多帧平均法：用三脚架固定相机，连续拍摄几十张或上百张同场景的照片，然后对这组图求平均。因为噪声是随机的，平均后噪声会趋近于零，得到一张相对干净的图，作为 y_{true}​。 2. 长曝光法：在极低ISO、非常充足的光线下，用很长的曝光时间拍一张几乎没有噪声的图，作为 y_{true}​。（缺点：需要特殊设备，且只适合静态场景。）

  • 损失函数 loss = L(pred, y_true) 中的第二个参数就是这个“标准答案”。
  • 训练时，没有 ytrueytrue​，就无法计算损失，也就无法反向传播和优化——模型就无法学习。
  • 简单记住：ytrueytrue​ = 模型想要逼近的“完美输出”。对于去噪任务，它就是“干净图”。

② 模型（Model）

  • 前向传播：计算 y^=fθ(x)\hat{y} = f_{\theta}(x)y^​=fθ​(x)，其中 θ\thetaθ 表示当前所有参数。
  • 初始时 θ\thetaθ 随机，所以 y^\hat{y}y^​ 完全是错的。

先理解“神经元”——模型的最小单元

一个神经元做的事可以写成一个公式：

a=σ(w1x1+w2x2+⋯+wnxn+b) a = \sigma(w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b) a=σ(w1​x1​+w2​x2​+⋯+wn​xn​+b)
  • x1,x2,…x_1, x_2, \dotsx1​,x2​,…：这个神经元接收的多个输入
  • w1,w2,…w_1, w_2, \dotsw1​,w2​,…：每个输入对应的权重（可调参数，决定输入的重要性）
  • bbb：偏置（可调参数，相当于一个基础偏移量）
  • σ\sigmaσ：激活函数（如 ReLU），用来引入非线性
  • aaa：这个神经元的输出

三个核心操作的作用：

  1. 加权和 ∑wixi\sum w_i x_i∑wi​xi​：把所有输入按重要程度累加，得到一个综合得分。
  2. 偏置 +b+ b+b：在综合得分上加一个独立于输入的常数，相当于调整神经元的激活门槛。
  3. 激活函数 σ\sigmaσ：将加权和+偏置的结果做非线性变换。如果没有激活函数，无论堆叠多少层，整个网络都只能表达线性关系（直线、平面），无法拟合现实世界的复杂问题（如图像去噪）。激活函数是神经网络能够“弯曲”空间、逼近任意非线性函数的关键。

从“一个神经元”到“神经网络模型”

  • 一个神经元只能做非常简单的判断。把大量神经元分层排列： 输入层 隐藏层1 隐藏层2 输出层 (3个) (4个) (4个) (2个)

    x1 ──┐ ├──→ 神经元1 ──┐ x2 ──┼──→ 神经元2 ──┼──→ 神经元1 ──┐ ├──→ 神经元3 ──┼──→ 神经元2 ──┼──→ 神经元1 ──→ ŷ1 x3 ──┘ 神经元4 ──┘ 神经元3 ──┼──→ 神经元2 ──→ ŷ2 神经元4 ──┘ (数据输入) (第一层) (第二层) (第三层)

  • 整个模型 fθf_\thetafθ​ 就是每一层神经元的输出作为下一层的输入，层层嵌套：

y^=fθ(x)=第L层(…(第1层(x))… ) \hat{y} = f_\theta(x) = \text{第L层}( \dots ( \text{第1层}(x) ) \dots ) y^​=fθ​(x)=第L层(…(第1层(x))…)
  • 参数 θ\thetaθ 包括所有层、所有神经元的权重和偏置。训练的目标就是不断调整这些成千上万个参数，使得 y^\hat{y}y^​ 越来越接近标准答案 ytruey_{true}ytrue​。

为什么初始输出完全是错的？ 训练开始时，所有权重和偏置都是随机的小数（比如 0.01, -0.03）。随机参数下的神经元组合等于一个随机函数——输入一张噪声图，输出的结果毫无意义（比如一片噪声或全黑）。只有通过反复的“前向→损失→反向→优化”循环，参数才会逐步变得有序，模型才能真正学会去噪。

模型和前向传播的关系是什么？ 模型是“函数”本身（参数化的计算公式），前向传播是“执行这个函数”——输入数据流过模型各层，最终算出预测结果的过程。

③ 损失（Loss）

损失函数 L(y^,ytrue)L(\hat{y}, y_{true})L(y^​,ytrue​) 是一个标量数字，用来量化模型预测值 y^\hat{y}y^​ 与真实值 ytruey_{true}ytrue​ 之间的“差距”。训练的核心目标就是通过反复调整模型参数，让这个数字尽可能降到最低。

深入理解：Loss 的本质与底层原理

1. Loss 到底在算什么？ 它计算的是两个高维向量之间的距离。你可以把 y^\hat{y}y^​ 和 ytruey_{true}ytrue​ 想象成空间中的两个点（例如一张 100×100100 \times 100100×100 的图就是一个 10000 维空间中的点）。Loss 就是这两个点之间的“直线距离”或“差异程度”。模型优化的过程，就是在高维空间中不断移动 y^\hat{y}y^​ 这个点，让它无限逼近 ytruey_{true}ytrue​ 这个目标点。

2. 为什么 Loss 必须是一个标量（单个数字）？ 模型参数可能有数百万个（θ={w1,w2,...,wn}\theta = \{w_1, w_2, ..., w_n\}θ={w1​,w2​,...,wn​}）。梯度下降算法（优化器）需要一个单一、具体的数值来衡量整体表现，才能计算出“梯度的方向”。如果 Loss 是向量，优化器就不知道朝哪个方向走。

3. 常见的 Loss 及其“个性”（为什么去噪任务特殊） 针对AIBNR 任务（恢复图像细节），选择不同的 Loss 就像用不同的标准去评判“好照片”：

  • L1 Loss（平均绝对误差，MAE）：计算每个像素预测值与真实值之差的绝对值的平均。

    • 个性：对异常值（比如极亮的坏点） 不敏感，比较“宽容”。在图像去噪中，它能较好地保留图像的纹理和边缘，但收敛速度相对较慢。

  • L2 Loss（均方误差，MSE）：计算每个像素之差的平方的平均。

    • 个性：因为平方了，它对大误差（比如大片噪点） 非常敏感（惩罚极重）。收敛快且数学性质好（处处可导）。但在图像任务中，它容易导致结果过度平滑，抹杀细节和纹理（因为把大误差抹平对降低 Loss 帮助最大）。

  • SSIM Loss（结构相似性损失）：不比较单个像素，而是比较局部窗口内像素之间的结构、亮度和对比度。

    • 个性：它更符合人眼视觉系统。人眼看一张图，关注的是边缘、纹理和结构，而不是每个像素的精确灰度值。因此 SSIM Loss 能显著提升画面的“观感”（干净且清晰）。

  • 感知损失（Perceptual Loss，在代码里叫 YUV Loss 或 pLoss 的变种）：利用一个额外的、预训练好的深度网络去提取 y^\hat{y}y^​ 和 ytruey_{true}ytrue​ 的高级语义特征（比如纹理、物体轮廓），然后比较这些特征的差异。

    • 个性：关注“内容”而非“像素”。它能让你恢复出的图像在人眼看来更真实、更清晰，而不是像素级的“平均模糊”。

4. 为什么代码里会有多个 Loss 组合（比如 raw_l1_loss + raw_ssim_loss）？ 这是工业界的常见“组合拳”。因为单一 Loss 总有缺陷：L1 保纹理但画面结构可能松垮；SSIM 保结构但可能过于锐利产生伪影。通过加权相加（例如 Loss = 1.0 * L1 + 1.0 * SSIM + ...），可以约束模型同时兼顾多个目标，达到最佳视觉效果。

Loss 在训练循环中的精确位置

参照核心学习循环：数据 → 模型 → ③ 损失（Loss） → 反向传播 → 优化器。

  1. 模型前向传播产生了预测图 y^\hat{y}y^​，训练代码中加载了标准答案 ytruey_{true}ytrue​。
  2. 代码调用计算函数（如 criterion(pred, target)），通过上述公式算出当前的 Loss 值（一个浮点数，如 0.235）。
  3. 这个 Loss 值随即被送入反向传播引擎。反向传播算法会计算“Loss 关于每一个参数 θ\thetaθ 的偏导数”（即梯度）。这里的核心数学工具就是链式法则——从 Loss 这个最末端的节点开始，往前一层一层求导，把“误差责任”分配给每一个神经元。

简单来说：Loss 是“分数”，反向传播是“阅卷分析”，优化器是“根据分析制定的提分策略”。

为什么设计一个好的 Loss 如此关键？

因为网络能学到什么，完全由 Loss 来定义。如果 Loss 只关注像素绝对误差，网络就会偷懒——输出一张模糊的平均图虽然看不清细节，但像素误差不大，Loss 就降下来了。如果你想让网络输出清晰的边缘，就必须在 Loss 中加入 SSIM 或感知损失，告诉它：“模糊的代价比像素误差更高”。在 AIBNR 中，设计一套好的 Loss 权重组合，往往是提升最终画质最重要的工作之一。

④ 反向传播（Backpropagation，BP）

反向传播计算损失 LLL 关于每一个模型参数 θi\theta_iθi​ 的偏导数 ∂L/∂θi\partial L / \partial \theta_i∂L/∂θi​。这些偏导数告诉优化器：如果微调这个参数，损失会增大还是减小？ 数学工具是链式法则——因为网络是一层接一层的复合函数，反向传播从最后一层往前一层层求导，把“责任”分摊给每个参数。

==反向传播原理详细可见：[[1.4 反向传播详解]]==

深入理解：反向传播的底层原理

1. 反向传播到底在算什么？

简单说：每个参数对最终 Loss 的“敏感程度”。

偏导数 ∂L/∂θi\partial L / \partial \theta_i∂L/∂θi​ 的含义是：当参数 θi\theta_iθi​ 发生微小的变化时，Loss 会变化多少。比如：

  • 如果偏导数为 正数（如 +0.5）：增大这个参数 → Loss 也会增大 → 模型变差，所以应该减小这个参数。
  • 如果偏导数为 负数（如 -0.3）：增大这个参数 → Loss 反而减小 → 模型变好，所以应该增大这个参数。
  • 如果偏导数为 0：这个参数对 Loss 没影响，调不调都行。

优化器拿到这些偏导数后，就按照“正数减小、负数增大”的规则来更新每个参数。这就是梯度下降的核心逻辑。

2. 为什么叫“反向”传播？

因为计算顺序和“前向传播”正好相反。前向传播是：

输入 x → 第1层 → 第2层 → 第3层 → ... → 输出 ŷ → 计算 Loss

反向传播的方向是：

Loss → 第L层 → 第L-1层 → 第L-2层 → ... → 第1层

从最后面往前一层一层地算，所以叫“反向”。

3. 核心数学工具：链式法则（Chain Rule）

神经网络本质上是一个复合函数：

y^=fL(fL−1(…f1(x)… )) \hat{y} = f_L( f_{L-1}( \dots f_1(x) \dots )) y^​=fL​(fL−1​(…f1​(x)…))

Loss 也是这个复合函数的最终结果：

L=L(fL(fL−1(…f1(x)… )),ytrue) L = L( f_L( f_{L-1}( \dots f_1(x) \dots )), y_{true} ) L=L(fL​(fL−1​(…f1​(x)…)),ytrue​)

要计算 Loss 对第1层参数的偏导数，需要一层一层“链”式地乘回去：

∂L∂θ1=∂L∂fL⋅∂fL∂fL−1⋅⋯⋅∂f2∂f1⋅∂f1∂θ1 \frac{\partial L}{\partial \theta_1} = \frac{\partial L}{\partial f_L} \cdot \frac{\partial f_L}{\partial f_{L-1}} \cdot \dots \cdot \frac{\partial f_2}{\partial f_1} \cdot \frac{\partial f_1}{\partial \theta_1} ∂θ1​∂L​=∂fL​∂L​⋅∂fL−1​∂fL​​⋅⋯⋅∂f1​∂f2​​⋅∂θ1​∂f1​​

这就是链式法则。每一层把自己的“导数”乘到结果上，不断往前传递。反向传播就是高效计算这个链式乘积的算法。

4. 一个具体的小例子

假设一个三层网络：输入 xxx → 隐藏层 h=w1⋅xh = w_1 \cdot xh=w1​⋅x → 输出 y^=w2⋅h\hat{y} = w_2 \cdot hy^​=w2​⋅h → Loss L=(y^−ytrue)2L = (\hat{y} - y_{true})^2L=(y^​−ytrue​)2。

要算 ∂L/∂w1\partial L / \partial w_1∂L/∂w1​：

  1. 先算 ∂L/∂y^=2(y^−ytrue)\partial L / \partial \hat{y} = 2(\hat{y} - y_{true})∂L/∂y^​=2(y^​−ytrue​)（输出层的误差）
  2. 再算 ∂y^/∂h=w2\partial \hat{y} / \partial h = w_2∂y^​/∂h=w2​（第2层对第1层的导数）
  3. 再算 ∂h/∂w1=x\partial h / \partial w_1 = x∂h/∂w1​=x（第1层对参数的导数）
  4. 乘起来：∂L/∂w1=2(y^−ytrue)⋅w2⋅x\partial L / \partial w_1 = 2(\hat{y} - y_{true}) \cdot w_2 \cdot x∂L/∂w1​=2(y^​−ytrue​)⋅w2​⋅x

可以清楚看到：输出层的误差 2(y^−ytrue)2(\hat{y} - y_{true})2(y^​−ytrue​) 通过 w2w_2w2​ 这个通道传回了第1层，这就是“误差反向传播”的直觉含义。

5. 反向传播在训练循环中的位置

参照核心学习循环：数据 → 模型 → 损失 → ④ 反向传播 → 优化器。

  1. 前向传播结束，得到 Loss（一个数字）。
  2. 调用 loss.backward()（PyTorch 中的一行代码），自动执行反向传播。
  3. ==反向传播从 Loss 这个节点开始，沿着网络拓扑结构逆向计算每个参数的偏导数，结果存储在 param.grad 中。== ==4. 优化器读取 param.grad，用这些梯度来更新参数。==
  4. 清空梯度（否则下一次会累加），进入下一个 batch。

6. 为什么反向传播是深度学习的“引擎”？

没有反向传播，我们就不知道每个参数该向哪个方向调整。在百万、千万级别的参数空间中，如果没有梯度信息，盲目随机尝试寻找最优值就像在大海里捞针。反向传播通过链式法则，在一次前向 + 一次反向的计算中，同时算出所有参数的最优调整方向，让训练变得高效可行。

一句话类比（接住你原来的考试比喻）

  • 前向传播：学生做了一套卷子，得到分数（Loss）。
  • 反向传播：老师阅卷后，发现分数不理想，于是逐题分析：是最后的大题丢分最多（输出层误差大），还是中间的计算步骤出了问题（隐藏层导数），还是最开始的审题就没对（输入层参数）？哪道题、哪个步骤、哪个知识点的权重最大，就把补习精力集中在那里。
  • 优化器：根据分析结果，制定提分计划——重点刷哪类题，每天多花多少时间。

⑤ 优化器（Optimizer）

优化器使用反向传播计算出的梯度（偏导数）来更新模型的参数，从而让损失（Loss）逐步降低。其核心公式为：

θnew=θ−η⋅∇θL \theta_{new} = \theta - \eta \cdot \nabla_\theta L θnew​=θ−η⋅∇θ​L
  • θ\thetaθ：模型当前的所有参数（权重和偏置）。
  • ∇θL\nabla_\theta L∇θ​L：损失函数 LLL 关于参数 θ\thetaθ 的梯度向量（即反向传播算出来的那一大串偏导数）。
  • η\etaη（学习率）：一个预先设定的正数，控制每次更新的步长。

先看看优化器在学习循环中的位置：

  ┌─────────────────────────────────────────────────────────────────────────┐
  │                                                                         │
  │   ① 数据       ② 模型       ③ 损失      ④ 反向传播     ⑤ 优化器      │
  │   (x, y_true) → (前向传播) → (算Loss) → (算梯度)  → (更新参数)        │
  │                    ↑                         │                         │
  │                    └─────────────────────────┘                         │
  │                    下一轮循环使用更新后的参数                             │
  └─────────────────────────────────────────────────────────────────────────┘

深入理解：优化器的底层原理与公式拆解

1. 为什么公式里是“减号”？

梯度 ∇θL\nabla_\theta L∇θ​L 指向的是损失函数上升最快的方向（朝这个方向调参数，Loss 会变得更大）。我们想要 Loss 变小，所以要反着来——往梯度的负方向走，所以公式中是“−η⋅∇θL-\eta \cdot \nabla_\theta L−η⋅∇θ​L”。这就是梯度下降（Gradient Descent）名字的由来。

2. 学习率（η\etaη）——“迈多大的步子”

学习率决定了每一次参数更新的幅度：

  • 学习率太大：就像下山时迈的步子太大，可能直接跨过山谷（最低点），甚至滚到对面的山坡上（Loss 反而飙升，训练发散）。
  • 学习率太小：就像迈着极其微小的碎步下山，虽然肯定能到山脚，但速度极慢，训练可能需要几周甚至几个月。

3. 什么是“梯度向量”？

在之前的反向传播章节中，我们为每一个参数 w1,w2,...,wnw_1, w_2, ..., w_nw1​,w2​,...,wn​ 都算出了一个偏导数。把这些偏导数按顺序排成一个巨大的列表，就是梯度向量 ∇θL\nabla_\theta L∇θ​L。

∇θL=[∂L∂w1,∂L∂w2,…,∂L∂wn] \nabla_\theta L = \left[ \frac{\partial L}{\partial w_1}, \frac{\partial L}{\partial w_2}, \dots, \frac{\partial L}{\partial w_n} \right] ∇θ​L=[∂w1​∂L​,∂w2​∂L​,…,∂wn​∂L​]

公式中 η⋅∇θL\eta \cdot \nabla_\theta Lη⋅∇θ​L 的意思是：用学习率去乘以这个向量中的每一个偏导数，得到每个参数各自需要调整的具体数值。

主流优化器：从 SGD 到 Adam

1. SGD（随机梯度下降）—— 最朴素的“统一步伐”

做法：每次更新时，对所有参数一视同仁，都使用同一个全局学习率 η\etaη。

类比：下山时，无论脚下是平坦的草地还是崎岖的岩石，都用完全相同的步幅往下走。

局限：如果某个参数已经接近最优值（平坦区域），继续用大步幅容易来回震荡，很难精准落到最低点。

2. Adam（自适应矩估计）—— 智能的“私人定制步伐”

Adam 是目前最常用的优化器。它不会对所有参数一视同仁，而是为每一个参数单独维护一个动态的学习率。

核心思想：它“记住”了每个参数的历史梯度情况。

  • 如果某个参数在过去一直朝同一个方向变化（说明它很稳定），Adam 会给它一个较大的步长，让它加速前进。
  • 如果某个参数一直在正负之间来回震荡（说明它很犹豫），Adam 会给它一个较小的步长，让它稳下来避免震荡。

类比：一个有经验的登山向导。遇到平坦大道时大步快跑；遇到悬崖峭壁或薄冰时，立刻放慢脚步，试探着走。Adam 比 SGD 收敛更快、更稳定，且对初始学习率的敏感度较低，因此深受工业界欢迎。

优化器在训练循环中的精确位置

参照核心学习循环：数据 → 模型 → 损失 → 反向传播 → ⑤ 优化器。

在 PyTorch 代码中，这三个步骤是连续调用的：

  1. loss.backward()：反向传播，计算梯度 ∇θL\nabla_\theta L∇θ​L，并存放在 param.grad 中。
  2. optimizer.step()：优化器读取 param.grad，应用公式 θnew=θ−η⋅∇θL\theta_{new} = \theta - \eta \cdot \nabla_\theta Lθnew​=θ−η⋅∇θ​L，完成所有参数的更新。
  3. optimizer.zero_grad()：将刚才计算出的梯度清零。因为下一次迭代会重新计算新的梯度，如果不清零，新旧梯度会累加在一起，导致更新方向错误。

一句话总结

反向传播计算出“往哪个方向走”（梯度），优化器决定“以多大的步子走”（学习率策略）。SGD 给所有参数统一步伐，Adam 则为每个参数量身定制步伐——它们共同合作，驱使模型参数不断优化，最终找到让 Loss 最小的那个点。

1.3 这个循环的宏观意义

  • 迭代视角：每跑一次循环，模型就向正确答案迈一小步。经过成千上万次迭代，损失降到一个很低的水平，模型就“学会”了去噪。
  • 数据驱动：你不需要手动设计去噪规则（比如“如果像素亮度>100且周围方差<3，则做中值滤波”）。所有规则都从数据中自动涌现。
  • 为什么有效：因为现实世界的很多问题（包括图像去噪）存在一个平滑的函数映射，而深度网络有足够的表达能力去近似它，同时梯度下降能找到足够好的局部最优解。
