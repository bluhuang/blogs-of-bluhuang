一个AI工程师的数字花园

代码、咖啡因与自动流水线

欢迎来到我的数字"垃圾场"——不是贬义，是那种堆满了宝藏的杂物间。

高中时流行 bullet journaling，我会在学校文具区买一本横线本，然后把所有东西塞进去：日记、待办、头脑风暴、数学草稿……大概填满了6本。那东西简直救命。现在，我把这个习惯搬到了网上。

关于我

我是一名AI工程师，曾在英国留学。在数据库内核的深海里泡了多年，专注于索引与性能优化。同时也在大模型、RAG和Agent领域持续探索，从系统底层到算法上层保持贯通。

这个数字花园会有什么？

  • 硬核笔记：RAG评估、混合检索、Agent设计模式——尽量写成人话。
  • 实战翻车：从0到1搭Agent的血泪史，包括但不限于"为什么向量检索结果像在随机游走"。
  • 工具链分享：我如何用 Obsidian + DeepSeek + GitHub Actions 实现全自动博客发布。

关于这个站 & 技术彩蛋

这个站的博客文章不是手动搬的——我写了一个自动流水线。它叫 auto-blog-poster，功能包括：

  • 监听我的 Obsidian 笔记仓库，一旦推送，自动触发。
  • 调用 DeepSeek API 自动脱敏（删公司名、人名）、润色语句、删掉"面试"相关内容。
  • 处理 Obsidian 的特殊语法（![[图片.png]] 自动复制并转链）。
  • 增量更新：只处理新增或修改的笔记，缓存哈希，避免浪费API额度。
  • 最后调用 Hugo 生成静态博客，并部署到 GitHub Pages。

效果：我只需要在 Obsidian 里写笔记，推送后几分钟，博客就自动更新了。目前已经稳定跑了 44+ 篇，支持分类卡片、树形导航、搜索、评论、数学公式。
