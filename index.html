什么是大模型？

  • BluHuang
  • Ai

📌 本章重点总结（大模型基础） 大模型本质：一个基于海量数据训练、通过预测下一个词来生成文本的“超级助理”。 Token：大模型处理文本的最小单位（非字非词），决定模型输入上限和API费用。 ==上下文窗口：模型单次能“看到”的Token总量（如128K），相当于一块固定大小的白板，写满后会遗忘早期内容。== ==无状态性：大模型本身没有记忆，每次调用都是全新开始；多轮对话的“记忆”全靠应用代码传递历史消息列表。== 对话角色：消息列表包含 system（系统提示，设定身份和规则）、user（用户输入）、assistant（模型历史回复）。 大模型的四大能力： 听懂人话，精准理解意图 逻辑思考，拆解任务、做决策 生成符合要求的各类内容 看懂规则，严格按要求执行 ==大模型的三大短板：== ==无执行能力，不能与外部世界交互 → 需要 Agent + 工具调用== ==知识有保质期，容易产生幻觉 → 需要 RAG== ==上下文窗口有限 → 需要 RAG 按需检索== 学习意义：后续的Prompt、Function Calling、RAG、Agent等技术，都是在弥补大模型的这些短板。 正文： 学 Agent 开发，第一件事是认识它的"大脑"：大模型

什么是Prompt？

  • BluHuang
  • Ai

📌 本章重点总结（Prompt基础） Prompt定义：你发给大模型的所有输入内容，包括指令、背景、示例、格式要求等（不只是一句问题）。 Prompt的重要性：大模型是 next-token 预测机器，输入越精准，输出越稳定。在 Agent 开发中，输出稳定性直接决定流水线可靠性。 User Prompt三要素：目标明确、背景充足、输出要求。缺一不可。 System Prompt三大用途：身份设定、行为规则、输出格式约束。它比 User Prompt 更“稳”，是 Agent 行为可预测的核心保障。 ==写好Prompt的6个核心原则：== ==给模型角色 → 缩小搜索空间，输出更专业== ==正向约束优于负向禁止 → 明确“要做什么”== ==喂足背景信息 → 减少幻觉== ==指定输出格式（最好给JSON示例）→ Agent 解析的关键== ==使用 Few-shot（给例子）→ 胜过写规则== ==要求“先思考再回答”（思维链）→ 提升复杂问题准确率== Prompt迭代调试：多准备典型输入，每次只改一个变量，观察输出变化。常见问题有对应排查方法。 总结：Prompt 是 Agent 的控制面板。System Prompt 定义身份边界，User Prompt 提供具体任务。后续的 Function Calling、RAG、Agent 都依赖于 Prompt 的设计质量。 正文： 上一章你已经搞清楚了大模型的底层逻辑：它是一个超级助理，你通过 messages 列表把内容传给它，它根据你给的上下文预测并生成回答。

排列（Permutation）类题型算法复习笔记 1. 题型识别 共同特征 输入通常是一个数组或数字序列。 要求对元素进行重新排列，满足某种顺序（如字典序、下一个排列、所有排列、第 k 个排列等）。 核心考察点往往是字典序（lexicographical order）、回溯、数学（阶乘）。 高频题号一览 题号 题目 一句话概括 31 Next Permutation 找字典序的下一个更大排列 46 Permutations 无重复元素的全排列 47 Permutations II 有重复元素的全排列（去重） 60 Permutation Sequence 求 1~n 的第 k 个排列 556 Next Greater Element III 正整数版本的下一个排列（31 的变体） 526 Beautiful Arrangement 计数符合特殊规则的排列（回溯/DP） 667 Beautiful Arrangement II 构造一个特殊差异数组（数学构造） 2. 核心解题套路总结：下一个排列（31 题） 三步法（经典字典序算法） 从右向左找第一个下降点 i 找到第一对相邻的 nums[i] < nums[i+1]，记下较小数的位置 i。 如果找不到，说明整个数组是降序，已经是最后一个排列，直接反转整个数组。

回文（Palindrome）串题型完整笔记 一、题型识别与核心特征 回文串问题都围绕一个核心定义： 回文串：正着读和倒着读一样的字符串。 问题类型通常分为三类： 验证/计数型：判断是否是回文、统计回文子串数量。 构造/分割型：分割出所有回文子串（回溯）、最少分割次数（DP）。 最长/极值型：找最长的回文子串。 所有问题的根基都是如何高效判断一个子串是回文。一旦熟练掌握了子串回文的判断，所有问题无非是在此基础上遍历、计数、分割或求极值。
