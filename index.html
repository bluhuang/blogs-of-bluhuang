第二层能力

真正适合长期运行的高级功能

不是每次全量重做，而是稳定地持续维护
01

跨仓库自动触发

私有 Obsidian 仓库推送后，通过事件驱动自动启动完整发布流程。

02

精准增量处理

使用哈希识别新增、修改和删除，只处理真正变化的笔记，避免重复调用模型。

03

AI 润色与缓存

调用 DeepSeek API 优化表达，并通过独立缓存保留已处理结果，兼顾质量与成本。

04

Obsidian 原生兼容

转换 Wiki 链接、图片引用与特殊语法，让本地笔记无需手工改写即可发布。

05

资源与状态持久化

同步图片和内容缓存，保存文件时间与处理状态，支持后续构建继续复用。

06

自动构建与验证

通过 Hugo 和 GitHub Actions 完成站点构建、校验与 GitHub Pages 部署。
