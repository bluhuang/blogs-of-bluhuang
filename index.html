关于这个站 & 自动化彩蛋

这个博客是全自动生成的——我写了一套自动化博客发布工具，名叫 auto-blog-poster。

它的工作流程：

  • 监听我们的 Obsidian 笔记仓库，一旦推送，自动触发。
  • 调用 DeepSeek API 自动对笔记进行AI润色，让文字更流畅、表达更清晰。
  • 处理 Obsidian 的特殊语法（如 ![[图片.png]] 自动复制并转链）。
  • 增量更新：只处理新增或修改的笔记，通过哈希缓存避免重复处理。
  • 最后调用 Hugo 生成静态博客，并部署到 GitHub Pages。

效果：我只需要在 Obsidian 里写笔记，推送后几分钟，博客就自动更新了。
支持分类卡片、树形导航、搜索、评论、数学公式。

  • Coding

1. 什么是堆？ 堆（Heap）是一种特殊的完全二叉树，通常用数组存储。 最大堆：每个父节点的值 大于等于 其子节点的值，堆顶为最大值。 最小堆：每个父节点的值 小于等于 其子节点的值，堆顶为最小值。 堆的核心操作（插入、删除）时间复杂度均为 O(log n)，获取极值为 O(1)。

排列（Permutation）类题型算法复习笔记 1. 题型识别 共同特征 输入通常是一个数组或数字序列。 要求对元素进行重新排列，满足某种顺序（如字典序、下一个排列、所有排列、第 k 个排列等）。 核心考察点往往是字典序（lexicographical order）、回溯、数学（阶乘）。 高频题号一览 题号 题目 一句话概括 31 Next Permutation 找字典序的下一个更大排列 46 Permutations 无重复元素的全排列 47 Permutations II 有重复元素的全排列（去重） 60 Permutation Sequence 求 1~n 的第 k 个排列 556 Next Greater Element III 正整数版本的下一个排列（31 的变体） 526 Beautiful Arrangement 计数符合特殊规则的排列（回溯/DP） 667 Beautiful Arrangement II 构造一个特殊差异数组（数学构造） 2. 核心解题套路总结：下一个排列（31 题） 三步法（经典字典序算法） 从右向左找第一个下降点 i 找到第一对相邻的 nums[i] < nums[i+1]，记下较小数的位置 i。 如果找不到，说明整个数组是降序，已经是最后一个排列，直接反转整个数组。

Application-Defined SQL Functions

  • BluHuang
  • Database

[[programming interfaces]] source: https://sqlite.org/appfunc.html 1 简介 SQLite 支持用户实现自定义回调方法，以实现一些特殊的自定义功能，类似于用户定义函数（UDF）。 自定义的 SQLite UDF 可以是标量函数、聚合函数或窗口函数。 通过此机制可以创建可在 SQL 查询中使用的自定义函数，这些函数可以用 C 语言编写，也可以通过在 Python、Java 等其他语言中绑定实现。 2 相关接口 sqlite3_create_function family 1 sqlite3_create_function() 基本信息 int sqlite3_create_function( sqlite3 *db, /* 数据库连接 */ const char *zFuncName, /* 函数名 (UTF-8) */ int nArg, /* 参数个数 (-1 = 可变) */ int eTextRep, /* 首选文本编码 */ void *pApp, /* 应用数据指针 */ void (*xFunc)(sqlite3_context*,int,sqlite3_value**), /* 标量函数 */ void (*xStep)(sqlite3_context*,int,sqlite3_value**), /* 聚合step函数 */ void (*xFinal)(sqlite3_context*) /* 聚合finalize函数 */ ); 特点 最基础版本：最早引入的函数注册接口 编码指定：使用 eTextRep 参数指定文本编码偏好 函数类型： 如果 xFunc 非 NULL，注册标量函数 如果 xStep 和 xFinal 非 NULL，注册聚合函数 应用数据：通过 pApp 传递用户数据 内存管理：无自动清理机制，需要手动管理内存 2 sqlite3_create_function16() 基本信息 int sqlite3_create_function16( sqlite3 *db, /* 数据库连接 */ const void *zFuncName, /* 函数名 (UTF-16) */ int nArg, /* 参数个数 */ int eTextRep, /* 首选文本编码 */ void *pApp, /* 应用数据指针 */ void (*xFunc)(sqlite3_context*,int,sqlite3_value**), void (*xStep)(sqlite3_context*,int,sqlite3_value**), void (*xFinal)(sqlite3_context*) ); 特点 UTF-16 支持：函数名使用 UTF-16 编码 向后兼容：为需要 UTF-16 函数名的应用提供支持 功能相同：与 sqlite3_create_function() 功能相同，只是函数名编码不同 使用场景： Windows API 集成（Windows 原生使用 UTF-16） 需要处理宽字符的遗留系统 3 sqlite3_create_function_v2() 基本信息 int sqlite3_create_function_v2( sqlite3 *db, /* 数据库连接 */ const char *zFuncName, /* 函数名 (UTF-8) */ int nArg, /* 参数个数 */ int eTextRep, /* 首选文本编码 */ void *pApp, /* 应用数据指针 */ void (*xFunc)(sqlite3_context*,int,sqlite3_value**), void (*xStep)(sqlite3_context*,int,sqlite3_value**), void (*xFinal)(sqlite3_context*), void (*xDestroy)(void*) /* 析构函数 */ ); 特点 增强版本：在基础版本上增加了析构函数 自动清理：通过 xDestroy 回调自动清理 pApp 数据 内存安全：避免内存泄漏，更安全 推荐使用：SQLite 官方推荐使用此版本 4 sqlite3_create_window_function 基本信息 int sqlite3_create_window_function( sqlite3 *db, /* 数据库连接 */ const char *zFuncName, /* 函数名 */ int nArg, /* 参数个数 */ int eTextRep, /* 首选文本编码 */ void *pApp, /* 应用数据指针 */ void (*xStep)(sqlite3_context*,int,sqlite3_value**), /* step函数 */ void (*xFinal)(sqlite3_context*), /* finalize函数 */ void (*xValue)(sqlite3_context*), /* value函数 */ void (*xInverse)(sqlite3_context*,int,sqlite3_value**), /* inverse函数 */ void (*xDestroy)(void*) /* 析构函数 */ ); 特点 窗口函数专用：专门用于注册窗口函数（SQLite 3.25.0+） 额外回调：需要实现更多回调函数 反向处理：支持 xInverse 用于优化窗口函数性能 复杂功能：支持滑动窗口、排序、分组等高级功能 3 UDF 类型 3.1 标量函数 (Scalar Functions) 接受参数，返回单个值 对每一行数据独立计算 示例：UPPER(), ABS(), DATE() 3.2 聚合函数 (Aggregate Functions) 跨多行数据操作，返回聚合结果 需要维护状态信息 示例：SUM(), AVG(), COUNT() 3.3 窗口函数 (Window Functions) SQLite 3.25.0+ 支持 在窗口帧上执行计算 示例：ROW_NUMBER(), RANK() 4 参数含义 int sqlite3_create_function_v2( sqlite3 *db, /* 数据库连接 */ const char *zFuncName, /* 函数名 (UTF-8) */ int nArg, /* 参数个数 */ int eTextRep, /* 首选文本编码 */ void *pApp, /* 应用数据指针 */ void (*xFunc)(sqlite3_context*,int,sqlite3_value**), void (*xStep)(sqlite3_context*,int,sqlite3_value**), void (*xFinal)(sqlite3_context*), void (*xDestroy)(void*) /* 析构函数 */ ); 4.1 zFunctionName 此参数传入方法名：第二个参数是要创建的 SQL 函数名。通常为 UTF8 编码，但 sqlite3_create_function16() 要求使用本机字节序的 UTF16 编码。 函数名长度限制为 255 字节（UTF8）。尝试创建名称更长的函数将导致 SQLITE_MISUSE 错误。 UDF 注册支持重载：可以用相同函数名多次调用这些创建接口。例如，若两次调用参数数量不同，则会注册同一函数名的两个变体，各接受不同数量的参数。 4.2 nArg 表示参数数量，int 类型 参数大小范围为 -1 至 127（最大值为 SQLITE_MAX_FUNCTION_ARG，即 32767）。 4.3 eTextRep 文本编码 类型：int（位掩码） 作用：指定函数的文本编码偏好 取值： SQLITE_UTF8 (0x01)：UTF-8 编码 SQLITE_UTF16LE (0x02)：UTF-16 小端序 SQLITE_UTF16BE (0x03)：UTF-16 大端序 SQLITE_UTF16 (0x04)：使用本地字节序的 UTF-16 SQLITE_ANY：接受任何编码（已废弃） 组合标志：可与确定性标志组合 4.4 pApp 详细说明 类型：void*（任意类型指针） 作用：传递用户自定义数据到函数 生命周期：由 xDestroy 回调管理 使用场景： 传递配置参数 传递共享资源（如缓存、文件句柄） 传递状态信息 4.5 xFunc 标量函数指针 详细说明 类型：函数指针 void (*)(sqlite3_context*, int, sqlite3_value**) 作用：标量函数的实现 调用时机：每次 SQL 查询需要函数值时调用 参数： sqlite3_context*：函数上下文，用于设置结果和错误 int：实际参数个数 sqlite3_value**：参数值数组
